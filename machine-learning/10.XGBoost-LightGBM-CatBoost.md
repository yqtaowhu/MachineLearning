# XGBoost、LightGBM、CatBoost

## 1. 概述

一句话概括：

- **XGBoost**：GBDT 的第一个工业级精修版 —— 在数学上加了**二阶泰勒展开**和**显式正则项**，在工程上靠 **Block 预排序 + 多线程并行**提速；
- **LightGBM**：面向"大数据、要更快"的实现 —— 用**直方图算法、Leaf-wise 生长、GOSS 采样、EFB 特征捆绑**四板斧把训练速度再提一档，同时内存大幅下降；
- **CatBoost**：面向"表格数据里到处都是类别特征"的实现 —— 用 **Ordered Boosting** 解决梯度估计偏差（prediction shift），用**有序目标编码**原生、无泄漏地处理类别特征，并用**对称树**保证推理速度快且不易过拟合。

为什么重要：这三个库是表格数据（结构化数据）竞赛和工业界落地的事实标准，理解它们的差异不仅能帮你在 Kaggle / 业务指标上省事，更是面试中出现频率最高的机器学习话题之一。本文默认你已了解 GBDT 的基本思想，可参考同目录 [4.树模型-梯度提升树.md](./4.树模型-梯度提升树.md)。

## 2. 核心原理

### 2.1 共同的基础：GBDT 的统一框架

三者都是 **加法模型 + 前向分步** 的梯度提升框架：第 $t$ 轮在当前累积预测上加一棵新树。

设第 $i$ 个样本在第 $t$ 轮前的预测值为 $\hat{y}_i^{(t-1)}$，本轮要学的树为 $f_t(\mathbf{x})$，损失函数为 $l(y_i, \hat{y}_i)$，目标函数为：

$$Obj^{(t)} = \sum_{i=1}^{n} l\big(y_i,\ \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)\big) + \Omega(f_t)$$

其中：
- $n$：样本数
- $\Omega(f_t)$：第 $t$ 棵树的复杂度惩罚项

对损失函数做**二阶泰勒展开**（去掉常数项），定义每个样本的一阶梯度和 $g_i$、二阶梯度和 $h_i$：

$$g_i = \frac{\partial\, l(y_i, \hat{y}_i^{(t-1)})}{\partial\, \hat{y}_i^{(t-1)}}, \qquad h_i = \frac{\partial^2\, l(y_i, \hat{y}_i^{(t-1)})}{\partial\, (\hat{y}_i^{(t-1)})^2}$$

得到近似目标：

$$Obj^{(t)} \approx \sum_{i=1}^{n} \Big[ g_i f_t(\mathbf{x}_i) + \frac{1}{2} h_i f_t^2(\mathbf{x}_i) \Big] + \Omega(f_t)$$

假设树有 $T$ 个叶子，第 $j$ 个叶子的输出分数为 $w_j$，把样本按所属叶子分组（$I_j$ 为落在叶子 $j$ 的样本集合），记 $G_j = \sum_{i \in I_j} g_i$，$H_j = \sum_{i \in I_j} h_i$，则目标可以重写为每个叶子上的独立二次函数之和：

$$Obj = \sum_{j=1}^{T} \Big[ G_j w_j + \frac{1}{2}(H_j + \lambda) w_j^2 \Big] + \gamma T$$

对每个叶子求极小值（令导数为零），得到**解析最优叶子权重**：

$$\boxed{\quad w_j^{*} = -\frac{G_j}{H_j + \lambda}, \qquad Obj^{*} = -\frac{1}{2}\sum_{j=1}^{T} \frac{G_j^2}{H_j + \lambda} + \gamma T \quad}$$

在一次二叉分裂中，左子节点 sums 为 $(G_L, H_L)$、右子节点为 $(G_R, H_R)$，父节点为 $(G_L+G_R,\ H_L+H_R)$，分裂带来的目标下降量为**分裂增益**：

$$Gain = \frac{1}{2} \Big[ \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda} \Big] - \gamma$$

只有 $Gain > 0$ 时才值得分裂，这就是内置的自动剪枝机制。**这个公式是三个库分裂决策的共同骨架**，它们的差异主要在于：①怎么扫候选分裂点（预排序 vs 直方图）；②怎么控制树的形状（level-wise / leaf-wise / 对称树）；③怎么估梯度最稳（普通 boosting / GOSS / Ordered Boosting）；④怎么喂特征（含缺失值、含高基数类别的原始列）。

### 2.2 XGBoost：二阶泰勒展开 + 工程优化

**数学层面**

1. **二阶泰勒展开**：像牛顿法一样同时利用一阶 $g_i$ 和二阶 $h_i$ 信息，相比 GBDT 只用一阶梯度（相当于更粗糙的一阶近似），收敛路径更准、步长自适应；
2. **显式正则项**：$\Omega(f_t) = \gamma T + \frac{1}{2}\lambda \sum_{j} w_j^2$，其中 $T$ 是叶子数（限制模型容量），$\lambda$ 对叶子分数做 L2 收缩（避免某个叶子独占巨大的修正量），还可以再加 $\alpha \|w\|_1$ 做 L1 稀疏化。

**工程层面**

1. **Block 结构 + 预排序**：训练前对每个特征做一次全局排序并压缩存成 Block（CSC 格式），之后每轮分裂查找只需线性扫描块内的已排序列，排序成本只花一次；
2. **特征级并行**：boosting 的"树与树之间必须串行"没有改变，但单个节点的分裂查找可在**不同特征的 Block 上多线程同时进行**，最后汇总找全局最优分裂——这才是 XGBoost 所谓"并行"的真实含义；
3. **近似分裂算法**：样本量大时不再枚举全部取值，而是按二阶梯度加权做分位数草图（weighted quantile sketch），把连续特征切成若干 bucket，只在 bucket 边界上尝试分裂；
4. **稀疏感知（sparsity-aware）**：缺失值不需要预先填充，为每个节点学习一个"缺失样本默认方向"，分裂时把缺该特征的样本全部划到使增益更大的那一侧；
5. **其他防过拟合手段**：shrinkage（学习率 $\eta$ 缩减每棵树贡献）、行采样（row subsample）、列采样（col subsample）。

### 2.3 LightGBM：三大提速技术

**(1) 直方图算法（Histogram）**

先把每个特征的取值离散化到固定数量 $k$ 个 bin（如 $k=255$，可用 uint8 存储），遍历样本时只做"找到 bin 编号 + 累加 $(G,H)$ 统计量"的操作：

- 时间复杂度从"排序的 $O(n\log n)$"降到"$O(n)$ 一次扫描 + $O(k)$ 扫桶"；
- 内存从存排好序的索引 "$O(2 \times n \times 数据条数 \times 32bit)$" 降到 "$O(k \times 特征数 \times 32bit)$ 量级"；

**直方图作差加速**是点睛之笔：父节点的直方图减去兄弟节点的直方图就得到另一个孩子节点的直方图，于是每次分裂只需为一个孩子重新统计，代价直接减半，且在树更深时累积收益更大。

**(2) Leaf-wise（best-first）生长**

- XGBoost 采用 **level-wise**：逐层同时分裂所有节点，无论该层节点增益是否值得分，浪费在对增益很小的节点上；
- LightGBM 采用 **leaf-wise**：每一步总是挑**当前所有叶子中增益最大的那个**继续往下分。同样叶子数下误差更低；
- 代价：容易长出很深的不平衡树而过拟合，所以要用 `num_leaves`（替代 `max_depth` 成为主要容量旋钮）配合 `max_depth`、`min_data_in_leaf` 一起限制。

**(3) 单边梯度采样（GOSS, Gradient-based One-Side Sampling）**

直觉：梯度绝对值越大的样本，说明当前预测离目标越远、"欠学习"，信息量越大；接近收敛的小梯度样本贡献有限。做法：

- 把样本按 $|g_i|$ 排序，**全部保留**梯度最大的前 $a \times n$ 个（top 组）；
- 从剩下 $(1-a)n$ 个小梯度样本中**随机采** $b \times n$ 个，并为它们赋予放大系数 $\frac{1-a}{b}$，保证改变后的分布和无放差尽量一致；

总计只用约 $(a+b)n$ 个样本参与建分裂统计，却基本保持了信息分布。

**(4) 互斥特征绑定（EFB, Exclusive Feature Bundling）**

高维稀疏特征往往大量互斥（不会同时非零）。EFB 通过图染色（冲突容忍版 Greedy Bundling）把这些稀疏列捆成一列：取值时加不同的偏移 offset 区分开，于是"几千个稀疏特征"变成"几十个稠密 bundle"，构建直方图的开销随之骤降。需要事先合并类别特征的 one-hot 或多值 sparse 列的场景尤其受益。

**(5) 原生类别特征支持**

类别特征无需 one-hot：分裂时按"类别对应的 $\sum g / (\sum h + \lambda)$"对类别排序，在该排序上扫描寻找最优切分（等价于把这些类别当成有序变量分组到左右两侧），天然避免了 one-hot 高基数下的特征碎片化和样本分散问题。

### 2.4 CatBoost：有序提升与类别特征

**(1) 问题：为什么要 Ordered Boosting？**

普通 GBDT 在第 $t$ 轮用的是同一个训练集上已经跑完 $t-1$ 轮的模型来算梯度。**既然这棵树也是在这批样本上训练的，那么用它去预估这些样本自己的梯度就会系统性偏乐观**（均值不等式意义上偏向 0），这在 CatBoost 论文中被称为 **prediction shift / 梯度估计偏差**——训练集上残差被低估了，最终削弱泛化能力。

**Ordered Boosting 的解法**：引入 $s$ 个训练数据的随机排列 $\sigma_1, \dots, \sigma_s$。对每一个样本，它在一棵"临时模型"上的梯度是用**排位比它早的样本**训练出来的模型来计算的（训练自己时不许"偷看"自己），这和在线学习的逻辑一致，使得梯度是无偏的。交换代价是需要维护多个中间模型，所以 CatBoost 经常被认为"理论漂亮但单线程慢"，实践中其推理端反而很快（见下文对称树）。

**(2) 类别特征：有序目标编码（Ordered Target Statistics）**

高基数类别特征（如 user_id、city）直接 one-hot 会维度爆炸，简单地把整列做 target encoding 又会带来**目标泄漏**（某样本的标签参与了它自己的特征构造，模型会"背标签"）。CatBoost 的做法是把类别值替换成一个**历史统计量**（TS，Target Statistic），配合平滑先验：

$$TS(cat) = \frac{\text{同类别历史上的 } \sum y + a \cdot p}{\text{同类别历史上的出现次数 } count + a}$$

其中 $p$ 是全体标签先验（如整体点击率），$a$ 是平滑系数（相当于给统计量"配了 $a$ 条虚拟先验样本"，防止样本极少时统计剧烈震荡）。"Ordered"体现在：对样本 $i$，只允许使用**在排列中排在它之前的样本**（或最早子集中训练出的模型）来统计这个 TS——细节可参考下面的例 3。

此外还支持两个补充策略：

- 低基数类别（数目 $\leq$ `one_hot_max_size`）直接 one-hot；
- 自动枚举类别组合（category combinations）：比如"城市 + 星期几"拼成新类别，扩展上下文信息，同样用有序 TS 编码。

**(3) 对称树（Oblivious Decision Trees）**

CatBoost 的树每一层都使用**同一个分裂条件**（depth-wise 且所有样本在同一层走同一个判断），形如一串 $depth$ 层的规则模板。好处：

- 叶子数最多 $2^{depth}$，可用索引数组表示，**推理极快**（非常适合线上服务延迟敏感场景）;
- 天然限制复杂度，不易过拟合并能充当强正则；
- 可以把单棵树转译成一条人类可读的规则序列，提高可解释性。

## 3. 三者核心区别对比

| 维度 | XGBoost | LightGBM | CatBoost |
|---|---|---|---|
| 数学核心 | 二阶泰勒展开 + 显式正则 | 与 XGBoost 同型（差别在工程） | 同型 + Ordered Boosting 降低梯度偏差 |
| 分裂点查找 | 预排序 Block（精确） + 加权分位数近似 | 直方图（bin 化，$O(n)$ 扫描） | 直方图 |
| 树生长策略 | level-wise 为主 | **leaf-wise**（按最大增益挑叶子） | depth-wise 对称树（每层共享分裂条件） |
| 并行方式 | 特征 Block 多线程求分裂、支持分布式 | 同左 + 可选 GPU 直方图 | 多线程 / GPU，CPU 实现相对保守 |
| 类别特征 | 不原生支持（需预处理） | 原生支持，按梯度均值排序类别 | **最强**：Ordered Target Statistics + 自动类别组合 |
| 缺失值 | 学习"默认方向" | 支持（NaN 走单独分支） | NaN 当作特殊类别参与分裂搜索 |
| 过拟合控制 | $\gamma T + \lambda\|w\|^2$、行列采样、shrinkage | leaf-wise 本身易过拟合，需 `num_leaves` 等约束 | 对称树 + Ordered Boosting 自带抑制 |
| 相对速度 | 中 | **最快**（海量样本+稀疏特征尤佳） | 小-中等数据最快赶不上 LightGBM，但推理很快 |
| 精度口碑 | 强 | 强（配合调参略胜于 XGBoost 场景常见） | 中小数据集与富类别特征场景常表现最好、默认参数较稳 |
| 典型适用 | 通用基线、可解释正则需求强 | 大规模数值主导、极高维稀疏特征 | 表格数据高基数类别特征多、追求开箱即用 |

选用经验（大白话版）：

1. **不知道选啥** → 先跑 LightGBM（速度快、调参成熟），XGBoost 做对照；
2. **类别特征一大堆（user_id、商品类目、地区）** → 优先试 CatBoost；
3. **数据量巨大（千万级以上）** → LightGBM 的直方图 + GOSS + EFB 优势显著；
4. **要求线上推理延迟最低或需要强可解释的规则式模型** → CatBoost 对称树；
5. **竞赛冲榜** → 三个都用，blend / stacking 融合。

## 4. 与其他概念的关系

- **vs 传统 GBDT**：三者都可以看作"同一颗 GBDT 的不同精致版本"。传统 GBDT 只用一阶梯度、用 CART 视角的回归树、不做稀疏和类别优化；XGBoost 补齐数学严谨性，LightGBM 补齐工程效率，CatBoost 补齐类别数据和梯度偏差两个软肋。
- **vs Random Forest**：RF 是 bagging——强树（深树、无剪枝）并行投票降方差；GBDT 家族是 boosting——弱树（浅树、有正则）串行累加降偏差。RF 主要靠多棵树互相稀释噪声，GBDT 靠一步步纠正前人的错误。
- **vs AdaBoost**：AdaBoost 通过调整样本权重突出难分类样本，本质是指数损失的 forward stagewise 加性建模；GBDT 直接改用任意可微损失 + 拟合梯度，是更一般化的框架，因此才有了今天这三个重型实现。
- **什么时候 GBDT 家族不是首选**：超高维稀疏文本（deep NLP 更强）、图像（CNN 主场）、在线实时流式样本频率极高的严格增量场景（考虑 FTRL 一类在线模型）。

## 5. 具体例子

### 例 1：手算 XGBoost 的一次节点分裂

**问题**：6 个贷款用户，任务是预测"是否会逾期"。当前一轮之前的模型预测还有残余误差，我们把平方损失 $l(y,\hat y) = (y-\hat y)^2$ 作用在这些样本上，得其梯度 $g_i = 2(\hat y_i - y_i)$、$h_i = 1$。用年龄作为分裂候选特征，$\lambda = 1$，$\gamma = 0$。问应不应该分裂？往哪边分？

**步骤**：

1. 样本按年龄升序排列（括号内为各自的 $g_i$）：

   $$\text{年龄：}\ 20(1.6),\ 25(1.2),\ 30(0.4),\ 35(-1.8),\ 40(-1.4),\ 45(-1.0)$$

   $g_i>0$ 表示当前预测偏高（这类人实际很少逾期），$g_i<0$ 表示预测偏低。

2. 全局 sums：$G = 1.6+1.2+0.4-1.8-1.4-1.0 = -1.0$，$H = 6$。父节点不分裂时 $Obj^* = -\frac{1}{2}\cdot\frac{(-1.0)^2}{6+1} = -0.071$。

3. 计算相邻分组的两种候选切分（扫描已排序列即可，这正是 XGBoost Block 扫描在做的事）：

   - 候选 A：切在 30 和 35 之间
     - 左：$G_L = 3.2,\ H_L = 3$；右：$G_R = -4.2,\ H_R = 3$
     - $Gain_A = \frac{1}{2}\Big[\frac{3.2^2}{3+1} + \frac{(-4.2)^2}{3+1} - \frac{(-1.0)^2}{6+1}\Big] - 0 = \frac{1}{2}[2.56 + 4.41 - 0.143] = 3.41$
   - 候选 B：切在 25 和 30 之间
     - 左：$G_L = 2.8,\ H_L = 2$；右：$G_R = -3.8,\ H_R = 4$
     - $Gain_B = \frac{1}{2}\Big[\frac{2.8^2}{2+1} + \frac{(-3.8)^2}{4+1} - 0.143\Big] = \frac{1}{2}[2.613 + 2.888 - 0.143] = 2.68$

**结果解读**：

- 最优切分为"年龄 ≤ 32.5 | 年龄 > 32.5"，增益 $3.41 > 0$，值得分裂；
- 若设 $\gamma = 4$，则两个候选的增益都会被扣到不足 0，触发自动剪枝——这就是 $\gamma$ 作为"每片叶子的准入门槛"的直觉含义；
- 新叶子权重 $w^{*}_{左} = -\frac{3.2}{3+1} = -0.80$（下调年轻用户的逾期风险分），$w^{*}_{右} = -\frac{-4.2}{3+1} = +1.05$（上调年长用户的逾期风险分），符合业务直觉：当前模型低估了老年人风险。

### 例 2：LightGBM 直方图作差与 GOSS 采样

**问题**：训练集 $n = 10{,}000$ 条，LightGBM 采用 GOSS 参数 $a = 0.2$（保留的大梯度比例）、$b = 0.2$（小梯度抽样比例），问实际参与分裂统计的有效样本规模是多少？为什么小梯度样本还要加权？

**步骤与计算**：

1. 按 $|g_i|$ 从大到小排序：
   - top 组保留前 $a \times n = 0.2 \times 10{,}000 = 2{,}000$ 条大梯度样本，不丢弃不加权；
   - 剩余 $(1-a)n = 8{,}000$ 条小梯度样本中随机抽 $b \times n = 2{,}000$ 条；
2. 对抽到的 2,000 条小梯度样本乘上放大系数：

   $$\text{weight} = \frac{1-a}{b} = \frac{1-0.2}{0.2} = 4.0$$

3. 有效梯度总量核对：$2{,}000 \times 1 + 2{,}000 \times 4 = 10{,}000$，与全量的期望梯度总和一致；

**结果解读**：

- 参与建直方图的样本从 10,000 降到 4,000（60% 减免），但梯度统计分布基本不变——这就是"**在小部分数据上无损加速**"的含义；
- 若不加权，小梯度那部分的代表名额会被压扁，直方图整体重心偏向大梯度区间，影响后续 leaf-wsie 搜索的公平性；
- 再叠加直方图作差：设父节点直方图 $P = [12, 85, 300]$，左孩子刚统计完 $L = [10, 30, 120]$，则右孩子无需重新扫描样本，直接 $R = P - L = [2, 55, 180]$ 即得，省一半建桶时间。

### 例 3：CatBoost 有序目标编码如何避免标签泄漏

**问题**：5 条按时间先后到达的广告曝光样本，特征为"城市"，标签 $y \in \{0,1\}$ 表示是否点击：

| 序号 | 城市 | $y$ |
|---|---|---|
| 1 | 北京 | 1 |
| 2 | 北京 | 0 |
| 3 | 上海 | 1 |
| 4 | 北京 | 1 |
| 5 | 上海 | 0 |

全局先验 $p = \frac{3}{5} = 0.6$，平滑系数 $a = 1$，使用有序编码 $TS = \dfrac{\text{此前同城市的}\sum y + a\,p}{\text{此前同城市的次数} + a}$。

**步骤与计算**（依次只用"比自己早"的数据）：

1. 第 1 条（北京）：历史上还没有任何北京样本 → $TS = \frac{0 + 1\times 0.6}{0 + 1} = 0.600$；
2. 第 2 条（北京）：此前北京有 1 条（$y=1$）→ $TS = \frac{1 + 0.6}{1 + 1} = 0.800$；
3. 第 3 条（上海）：此前上海还没出现过 → $TS = \frac{0 + 0.6}{0 + 1} = 0.600$；
4. 第 4 条（北京）：此前北京 2 条（$\sum y = 1$）→ $TS = \frac{1 + 0.6}{2 + 1} = 0.533$；
5. 第 5 条（上海）：此前上海 1 条（$y=1$）→ $TS = \frac{1 + 0.6}{1 + 1} = 0.800$。

**结果解读**：

- 关键在第 1 条：即便它的真实 $y = 1$，它的特征值仍然是"盲猜"先验 0.600，**自己无法通过特征把标签泄给自己**；如果是普通的全局 target encoding，第 1 条的 TS 会带上自己的 $y=1$，模型很容易学出"$TS = 1 \Rightarrow$ 必然点击"这种背标签的伪规律，一上线就崩；
- 平滑的作用在第 4 条可见：北京已有 2 条历史（1 个正例），若不平滑则为 $\frac{1}{2}=0.5$，加上先验 $a=1$ 后退向总体水平 0.533，样本越少越接近全局均值，避免小样本抖动；
- Ordered Boosting 是同一思想的放大版：不只编码这一步，连**梯度估计**也坚持"用于训练 $i$ 号样本梯度的模型不能见过样本 $i$"，从而消除 prediction shift。

## 6. 常见面试问题

**Q1：XGBoost 为什么快？请从算法和工程两方面回答。**

答：算法层面——①对损失做二阶泰勒展开后，目标变成了关于叶子分数的二次函数，可以直接写出解析解 $w_j^{*} = -G_j/(H_j+\lambda)$，无需迭代；②分裂查找提前计算好 $G, H$ 前缀和，剪枝依据增益闭式可得。工程层面——①训练开始前对每个特征一次性预排序并压缩存储为 Block（CSC 列压缩格式），后续所有轮次复用，排序开销只发生一次；②分裂查找在不同特征的 Block 上多线程并行（特征级并行）；③块内按梯度累计访存做了 CPU cache 优化，block 还支持核外（out-of-core）计算应对超大数据。注意：树与树之间仍是串行的（boosting 本质决定），"并行"指的是**特征维度上的分裂查找并行**。

**Q2：XGBoost 为什么要做二阶泰勒展开？只用一阶（像 GBDT）不行吗？**

答：可以做，但结果更粗。展开到二阶后目标函数是叶子分数的**二次多项式**，从而有闭式最优解 $w^{*} = -G/(H+\lambda)$ 与统一的目标度量 $Obj^{*}$，剪枝和分裂决策都有了统一的量化标准。同时 $h_i$ 让每个样本自带"曲率"信息：曲率大（损失随预测变化陡）的地方步长自然被压小，起到类似自适应学习率的作用。直觉类比：一阶法只知道"往哪边走"，二阶法还知道"地面的坡度变化有多陡，该迈多大步"。

**Q3：XGBoost 如何防止过拟合？至少说出 4 种手段。**

答：①正则项 $\Omega(f) = \gamma T + \frac{1}{2}\lambda \sum w^2$：惩罚叶子个数和叶子分数的 L2 范数，$\gamma$ 相当于分裂准入门槛；②shrinkage：每轮把新树乘以学习率 $\eta$，减小每棵树的话语权；③行采样与列采样：借鉴随机森林，每棵树/每次分裂只见部分样本与特征；④min_child_weight：限制叶子上的 $\sum h$ 最小值，太小的叶子不建立；⑤树深度/叶子数上限；⑥early stopping。前三条是最常被追问的"教科书答案"。

**Q4：LightGBM 的直方图算法为什么比 XGBoost 的预排序快？"直方图作差"是什么？**

答：预排序需要在每一次分裂候选处按特征值扫过全部样本，复杂度 $O(n)$ 量级 × 多次遍历 + 排序成本；直方图算法先把特征离散化为 $k$ 个 bin（$k$ 通常远小于 $n$，例如 255），一次 $O(n)$ 线性扫描完成累计 $(G,H)$ 后，分裂查找只需要在 $k$ 个桶间做聚合比较，复杂度与 $n$ 解耦。内存也从保存每条样本的排序索引降为只需 $k \times$ 特征数的计数与累加器，特别适合大数据。"直方图作差"利用父子关系：父亲直方图 = 左孩子 + 右孩子，因此构建两个孩子时只需完整扫描一个，另一个用减法得出，分裂统计成本近乎减半，层数越深节省越多。

**Q5：Leaf-wise 和 Level-wise 有什么区别？leaf-wise 会带来什么问题？**

答：Level-wise（XGBoost 传统模式）逐层处理所有节点，同一层里增益很小的节点也会照常分裂，浪费计算；Leaf-wise（LightGBM）在当前所有叶子中永远挑增益最大的继续向下分裂，同样的 `num_leaves` 预算下能达到更低的训练损失。副作用是长出的树不平衡（一侧可以很深），在大数据上更容易过拟合，因此 LightGBM 把容量控制权交给 `num_leaves` 这个超参，并配合 `max_depth`、`min_data_in_leaf` 来兜底。经验法则：同精度下 LightGBM 往往用更少的叶子。

**Q6：简述 GOSS 的做法与权重公式的直觉。**

答：GOSS 按梯度绝对值排序后：保留 top $a$ 比例的大梯度样本全部参与；从小梯度集合随机抽取 $b$ 比例的样本，并把它们的梯度乘以 $\frac{1-a}{b}$。直觉：大梯度样本没学好、带的信息多，一个都不能丢；小梯度样本大多已接近收敛，丢一些没关系，但要给留下的"代表们"加权 $\frac{1-a}{b}$，让它们在统计上等价地代表整个被舍弃群体的贡献，这样抽样后的梯度分布期望与原分布一致，估计无系统偏差，计算量却降到原来的约 $(a+b)$。

**Q7：CatBoost 提出 Ordered Boosting 到底想解决什么问题？**

答：解决**梯度估计偏差（prediction shift）**。普通 GBDT 里，第 $t$ 轮用来拟合的那批样本正是之前 $t-1$ 轮模型在其上做过（间接）优化的样本，因此"用旧模型算的残差 + 在同一批样本上训新树"会让新树对这些样本的预测系统性偏向乐观（残差被低估），进而伤害泛化。Ordered Boosting 借助一组随机排列，让"训练样本来估计梯度所用到的模型"永远不包含该样本自身（类似把任务拆成若干份在线学习视角的子问题），从构造上消除了这个偏差。代价是要维护多个中间模型与多种数据视图，训练更费时间和内存，换来的是在小数据集上通常更好的泛化和稳定性。

**Q8：CatBoost 是如何在高基数类别特征上避免标签泄漏的？结合平滑公式说明。**

答：两个动作。第一，**有序目标编码**：把每个类别值替换成只由"排序中在它之前"的同类别样本计算的标签统计量 $\frac{\sum y + a p}{count + a}$，$p$ 为全局先验，$a$ 控制向先验回拉的强度；这样任何样本的特征构造都不包含它自身的标签，杜绝了 target leakage。第二，**可选 one-hot + 类别组合**：低基数（低于 `one_hot_max_size`）直接 one-hot，多重类别特征可以自动组合成新的复合类别再走同样的有序 TS 流程。平滑公式里的 $a$ 特别关键：当类别出现次数很少时，分子分母都被先验拉向全局水平，防止"只见过一次某城市就把 TS 定到极端值"的噪声过拟合。

**Q9：给你一个 500 万行、150 个数值特征 + 60 个高基数类别特征的 CTR 任务，选哪个库？怎么设置？**

答：首选 LightGBM 打底 + CatBoost 做横向对照。理由：数据量大（直方图 + EFB 能显著压缩 210 列宽表的建桶耗时）、数值列占大头（GOSS 提速收益明显）；高基数类别虽然 CatBoost 处理最优雅，但 LightGBM 的"按梯度均值对类别排序"也能 native 支持。具体建议：`num_leaves` 从 64~256 之间搜索并盯紧验证集早停；开启 `feature_fraction` / `bagging_fraction` 正则；类别列声明为 categorical 而非手工 one-hot（避免维度爆炸）；以单折 AUC 为尺子，如果 CatBoost 明显领先再考虑把它融合进来（logit 平均或 stacking）。

**Q10（进阶）：有人说"XGBoost 是并行算法"，这对吗？XGBoost、LightGBM、CatBoost 各自的并行化发生在什么层面？**

答：不对，至少不完全对。Boosting 的依赖链决定了**树与树之间必然串行**，任何"真正的 boosting 都不可能整体并行"。三家的并行都在**局部的、可拆分的计算单元**上展开：①XGBoost：把训练前建好的每个特征的 Block 交给多线程同时找最优分裂（特征级并行），以及块内基于 SIMD/cache 的向量化扫描，分布式场景再叠加数据/特征划分的 worker 并行；②LightGBM：除特征级并行外，直方图构建也可以并行分桶合并，并提供专门针对 GPU 友好的直方图实现、并行投票（Voting Parallel）减少通信；③CatBoost：多线程支持较弱但对 GPU 的 CTR 分类支持很好，同时对称树结构使其 CPU/GPU 推理都可高度向量化。一句话总结：**"哪里独立，就在哪里并行"——独立的是特征和分桶，而不是树本身。**
