# 卷积神经网络 CNN 详解

## 1. 概述

**一句话定义**：CNN（Convolutional Neural Network）是一种专门处理**网格结构数据**（如图像的像素网格、音频的频谱图）的深度学习模型，通过**局部连接**和**权值共享**大幅减少参数量，同时保留空间结构信息。

**为什么重要**：CNN 是计算机视觉领域的基石，在图像分类、目标检测、语义分割等任务上取得了突破性进展，也是理解现代视觉模型（包括 ViT）的基础。

> **直觉理解**：CNN 模仿生物视觉皮层的处理方式——神经元只响应局部视野（感受野），且对同一特征在不同位置使用相同的检测器（权值共享）。

## 2. 核心原理

### 2.1 卷积操作

卷积的核心是**滤波器（Filter）**在输入上滑动，逐元素相乘后求和，生成特征图（Feature Map）。

**二维卷积公式**：

$$
(X * K)_{i,j} = \sum_{m=0}^{k_h-1} \sum_{n=0}^{k_w-1} X_{i+m, j+n} \cdot K_{m,n}
$$

其中：
- $X$：输入特征图，形状 $(H_{in}, W_{in})$
- $K$：卷积核（滤波器），形状 $(k_h, k_w)$
- $(i, j)$：输出特征图的坐标位置
- $k_h, k_w$：卷积核的高度和宽度

**多通道卷积**（如 RGB 图像或深层网络的多个特征图）：

$$
Y_c = \sum_{c'=0}^{C_{in}-1} (X_{c'} * K_{c,c'}) + b_c
$$

其中：
- $C_{in}$：输入通道数
- $C_{out}$：输出通道数（即卷积核数量）
- $K_{c,c'}$：第 $c$ 个输出通道对第 $c'$ 个输入通道的卷积核
- $b_c$：偏置项

**PyTorch 实现**：

```python
import torch
import torch.nn as nn

# 输入：(batch=2, channels=3, height=8, width=8)
x = torch.randn(2, 3, 8, 8)

# 卷积层：输出 6 个通道，3×3 卷积核，步长 1，padding=1 保持尺寸不变
conv = nn.Conv2d(in_channels=3, out_channels=6, kernel_size=3, 
                 stride=1, padding=1, bias=True)

# 输出：(batch=2, channels=6, height=8, width=8)
y = conv(x)
print(y.shape)  # torch.Size([2, 6, 8, 8])
```

**关键参数**：
| 参数 | 作用 | 典型取值 |
|------|------|---------|
| `kernel_size` | 卷积核大小 | 3×3, 5×5, 7×7 |
| `stride` | 步长（滑动间隔） | 1, 2 |
| `padding` | 填充（边界补零） | 0, 1, 2... |
| `dilation` | 空洞率（扩大感受野） | 1, 2, 4... |
| `groups` | 分组卷积 | 1, C, min(C, out_channels) |

**Padding 模式**：
- **Valid**（无填充）：输出尺寸缩小
- **Same**（自动填充）：输出尺寸与输入相同（当 stride=1 时）
- **自定义**：手动指定填充量

### 2.2 池化操作

池化用于**下采样**，降低特征图分辨率，扩大感受野，提供平移不变性。

**常见池化类型**：

1. **最大池化（Max Pooling）**：取窗口内最大值
   $$\text{MaxPool}_{i,j} = \max_{(m,n) \in \text{window}} X_{i+m, j+n}$$

2. **平均池化（Average Pooling）**：取窗口内平均值
   $$\text{AvgPool}_{i,j} = \frac{1}{k_h k_w} \sum_{(m,n) \in \text{window}} X_{i+m, j+n}$$

3. **全局平均池化（Global Average Pooling）**：对整个特征图做平均，替代全连接层

**PyTorch 实现**：

```python
# 最大池化：2×2 窗口，步长 2
pool_max = nn.MaxPool2d(kernel_size=2, stride=2)

# 平均池化
pool_avg = nn.AvgPool2d(kernel_size=2, stride=2)

# 输入：(batch=2, channels=64, height=16, width=16)
x = torch.randn(2, 64, 16, 16)

# 输出：(batch=2, channels=64, height=8, width=8)
y_max = pool_max(x)
y_avg = pool_avg(x)
```

### 2.3 特征图尺寸计算

**卷积后尺寸**：

$$
H_{out} = \left\lfloor \frac{H_{in} + 2p - d(k_h - 1) - 1}{s} \right\rfloor + 1
$$

$$
W_{out} = \left\lfloor \frac{W_{in} + 2p - d(k_w - 1) - 1}{s} \right\rfloor + 1
$$

其中：
- $H_{in}, W_{in}$：输入高度和宽度
- $k_h, k_w$：卷积核高度和宽度
- $s$：步长（stride）
- $p$：填充（padding）
- $d$：空洞率（dilation）

**简化公式**（当 $d=1$ 时）：

$$
H_{out} = \left\lfloor \frac{H_{in} - k_h + 2p}{s} \right\rfloor + 1
$$

**池化后尺寸**：同样公式，将 $k$ 替换为池化核大小。

**实例验证**：

```python
# 输入：8×8，卷积核 3×3，stride=1，padding=1
# H_out = (8 - 3 + 2*1) / 1 + 1 = 8 ✓

conv = nn.Conv2d(3, 6, kernel_size=3, stride=1, padding=1)
x = torch.randn(2, 3, 8, 8)
y = conv(x)
assert y.shape[2] == 8 and y.shape[3] == 8  # 尺寸保持不变
```

## 3. 经典 CNN 架构演进

### 3.1 LeNet-5

> **论文**：LeCun et al., 1998. *Gradient-Based Learning Applied to Document Recognition*

**设计特点**：
- 输入：32×32 灰度图像 → 输出：10 类数字
- 结构：Conv → Pool → Conv → Pool → FC × 3 → Softmax
- 卷积核：5×5, 4×4 池化
- 激活：**Tanh**（当时 ReLU 还未普及）

**参数量**：约 60K（非常小，适合当时的硬件）

**历史意义**：第一个成功应用于实际场景（手写数字识别）的 CNN。

### 3.2 AlexNet

> **论文**：Alex Krizhevsky et al., 2012. *ImageNet Classification with Deep Convolutional Neural Networks*

**设计特点**：
- 输入：227×227 RGB 图像 → 输出：1000 类
- 结构：5 个 Conv 层 + 3 个 FC 层
- **ReLU 激活**：首次大规模使用，训练速度提升 6 倍
- **Dropout**：在 FC 层使用 Dropout（p=0.5）防止过拟合
- **数据增强**：随机裁剪、水平翻转
- **GPU 训练**：双卡并行训练（开创性）

**关键改进**：
```
Conv1: 11×11, stride=4, 96 个核
Conv2: 5×5, stride=1, 256 个核
Conv3: 3×3, 384 个核
Conv4: 3×3, 384 个核
Conv5: 3×3, 256 个核
FC6: 4096 维 + Dropout
FC7: 4096 维 + Dropout
FC8: 1000 维（Softmax）
```

**性能**：Top-1 错误率 37.5%（第二名 26.2%），一战成名！

### 3.3 VGG

> **论文**：Simonyan & Zisserman, 2014. *Very Deep Convolutional Networks for Large-Scale Image Recognition*

**设计思想**：**深度**比宽度更重要，用小的卷积核堆叠代替大的卷积核。

**核心创新**：
- **2×3×3 卷积堆叠**：两个 3×3 卷积的接收野 = 一个 5×5，但参数更少
  - 2×3×3: $2 \times (3 \times 3 \times C^2) = 18C^2$
  - 1×5×5: $1 \times (5 \times 5 \times C^2) = 25C^2$
  - **节省 28% 参数**！

**VGG16 结构**（最经典版本）：
```
Conv: 64 个 3×3 → Pool(2×2)
Conv: 128 个 3×3 → Pool
Conv: 256 个 3×3 → Conv 256 个 3×3 → Pool
Conv: 512 个 3×3 → Conv 512 个 3×3 → Conv 512 个 3×3 → Pool
Conv: 512 个 3×3 → Conv 512 个 3×3 → Conv 512 个 3×3 → Pool
FC: 4096 → FC: 4096 → FC: 1000 (Softmax)
```

**参数量**：138M（主要是 FC 层占 74%）

**特点**：结构简单优雅，适合作为其他模型的 backbone，但参数量大、推理慢。

### 3.4 GoogLeNet (Inception)

> **论文**：Szegedy et al., 2015. *Going Deeper with Convolutions*

**核心思想**：**多尺度特征融合**——在同一层使用不同大小的卷积核（1×1, 3×3, 5×5）+ 池化，然后拼接。

**Inception Module 结构**：
```
输入：(H, W, C)
├─ 1×1 卷积 → 提取通道间关系
├─ 3×3 卷积（先 1×1 降维）→ 提取局部特征
├─ 5×5 卷积（先 1×1 降维）→ 提取更大感受野
└─ 3×3 池化 + 1×1 卷积 → 保留多尺度信息
输出：拼接所有分支 → (H, W, C_new)
```

**关键技巧**：
1. **1×1 卷积降维**：大幅减少计算量
   - 例如：输入 192 通道，直接用 5×5 卷积到 32 通道需要 $192 \times 5 \times 5 \times 32 = 153,600$ 参数
   - 先用 1×1 降到 16 通道，再用 5×5：$192 \times 1 \times 1 \times 16 + 16 \times 5 \times 5 \times 32 = 3,072 + 12,800 = 15,872$
   - **压缩 10 倍**！

2. **网络模块化**：Inception 模块重复使用，易于扩展

3. **辅助 Softmax**：在中间层加辅助分类器，缓解梯度消失

**GoogLeNet 深度**：22 层（按卷积层计）或 44 层（按参数量计），刷新 ImageNet 纪录（Top-5 错误率 3.57%）

### 3.5 ResNet

> **论文**：He et al., 2015. *Deep Residual Learning for Image Recognition*

**核心突破**：**残差连接（Skip Connection）** 让训练数百甚至上千层的网络成为可能。

**问题背景**：网络越深，训练误差反而越大（退化问题）——不是过拟合，而是优化困难。

**残差块设计**：
$$
y = F(x) + x
$$

其中 $F(x)$ 通常是：
- **BasicBlock**：Conv → BN → ReLU → Conv → BN（两层）
- **Bottleneck**：1×1 降维 → 3×3 → 1×1 升维（三层，更高效）

**ResNet18/34**（使用 BasicBlock）：
```
Conv3×7, stride=2, 64 核 → MaxPool(3×3, stride=2)
├─ ResBlock(64, 64) × 2
├─ ResBlock(128, 128) × 3
├─ ResBlock(256, 256) × 7
└─ ResBlock(512, 512) × 2 → GAP → FC(1000)
```

**ResNet50/101/152**（使用 Bottleneck）：
```
每个 ResBlock 内部：
Conv 1×1 (C_in → C_out/4) → BN → ReLU
Conv 3×3 (C_out/4 → C_out/4) → BN → ReLU
Conv 1×1 (C_out/4 → C_out) → BN
+ 恒等映射 → ReLU
```

**关键发现**：
- 1000 层网络也能训动！
- 残差学习更容易：学 $F(x) = 0$ 比学 $H(x) = x$ 简单
- 成为 CV 领域**事实标准** backbone

### 3.6 EfficientNet

> **论文**：Tan & Le, 2019. *EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks*

**核心贡献**：系统性地研究**如何扩展 CNN**，提出**复合缩放方法**。

**三种扩展策略**：
1. **加深网络**（Depth）：增加层数
2. **加宽网络**（Width）：增加通道数
3. **提高分辨率**（Resolution）：增大输入图像尺寸

**发现问题**：均匀扩展某一种维度效果有限，需要**联合优化**三者比例。

**复合系数公式**：

$$
\text{depth} = \alpha^\phi, \quad \text{width} = \beta^\phi, \quad \text{resolution} = \gamma^\phi
$$

约束条件：
$$
\alpha \geq 1, \; \beta \geq 1, \; \gamma \geq 1, \quad \alpha \cdot \beta^2 \cdot \gamma^2 \approx 2, \quad \alpha \geq \beta \geq \gamma
$$

通过**神经架构搜索（NAS）**找到最优比例：$\alpha=2.0, \beta=1.2, \gamma=1.1$

**EfficientNet-B0 ~ B7**：
| 版本 | 参数量 | FLOPs | Top-1 Accuracy |
|------|--------|-------|----------------|
| B0 | 5.3M | 0.3B | 77.0% |
| B7 | 66M | 3.4B | 84.3% |

**优势**：相比 VGG/ResNet，在相同精度下**少 10 倍参数、少 10 倍计算量**。

## 4. 感受野（Receptive Field）

**定义**：特征图上某个点对应原图的区域大小。

**递归计算公式**：

$$
RF_l = RF_{l-1} + (k_l - 1) \cdot \prod_{i=1}^{l-1} s_i
$$

其中：
- $RF_l$：第 $l$ 层的感受野
- $k_l$：第 $l$ 层的卷积核大小
- $s_i$：第 $i$ 层的步长

**初始值**：$RF_0 = 1$

**实例计算**（ResNet18 第一块残差后）：
```
输入：224×224
Layer1:
  Conv7×7, stride=4 → RF = 7
  MaxPool3×3, stride=2 → RF = 7 + (3-1)*4 = 15
  
Layer2 (两个 3×3 卷积，stride=1):
  Conv1: RF = 15 + (3-1)*1 = 17
  Conv2: RF = 17 + (3-1)*1 = 19
```

**为什么重要**：
- 感受野决定模型能看到的"上下文范围"
- 目标检测中，检测大物体需要大感受野
- 现代 CNN 最后一层的感受野通常在 30~50 左右

| 模型 | 深度 | 参数量 | 核心创新 | 适用场景 |
|------|------|--------|---------|---------|
| LeNet-5 | 8 层 | 60K | 首个 CNN | 手写数字识别 |
| AlexNet | 8 层 | 60M | ReLU+Dropout | ImageNet 突破 |
| VGG16 | 16 层 | 138M | 小卷积核堆叠 | Backbone、特征提取 |
| GoogLeNet | 22 层 | 6.6M | Inception 多尺度 | 高精度分类 |
| ResNet50 | 50 层 | 25M | 残差连接 | 检测/分割 backbone |
| EfficientNet | 可变 | 5~66M | 复合缩放 | 移动端/资源受限 |

**选型建议**：
- **追求精度**：EfficientNet-Large / ResNet152
- **速度与精度平衡**：ResNet50 / EfficientNet-B3
- **移动端部署**：MobileNet / ShuffleNet（深度分离卷积）
- **教学/实验**：VGG16（结构简单易理解）

## 6. 具体例子

### 例子 1：手动计算 CNN 输出尺寸

**问题**：输入图像 224×224×3，经过以下层后，输出尺寸是多少？

```
Conv1: 7×7 卷积，stride=4, padding=3
Conv2: 3×3 最大池化，stride=2
Conv3: 3×3 卷积，stride=1, padding=1
```

**步骤**：

**Conv1**：
$$H_{out} = \frac{224 - 7 + 2 \times 3}{4} + 1 = \frac{225}{4} + 1 = 56.25 \to 56$$

**Conv2**（池化）：
$$H_{out} = \frac{56 - 3}{2} + 1 = 27.5 \to 27$$

**Conv3**：
$$H_{out} = \frac{27 - 3 + 2 \times 1}{1} + 1 = 26 + 1 = 27$$

**结果**：最终输出尺寸为 **27×27**

**验证代码**：
```python
import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=7, stride=4, padding=3),
    nn.MaxPool2d(kernel_size=3, stride=2),
    nn.Conv2d(64, 128, kernel_size=3, stride=1, padding=1)
)

x = torch.randn(1, 3, 224, 224)
y = model(x)
print(y.shape)  # torch.Size([1, 128, 27, 27]) ✓
```

### 例子 2：感受野计算实战

**问题**：计算 VGG16 中第一个 5×5 感受野的位置（即第二个 Conv2_2 层）的感受野。

**网络结构**：
```
Conv1_1: 3×3, stride=1
Conv1_2: 3×3, stride=1
Pool1: 2×2, stride=2
Conv2_1: 3×3, stride=1
Conv2_2: 3×3, stride=1  ← 目标位置
```

**逐步计算**：

1. **Conv1_1**：$RF = 1 + (3-1) \times 1 = 3$
2. **Conv1_2**：$RF = 3 + (3-1) \times 1 = 5$
3. **Pool1**：$RF = 5 + (2-1) \times 1 = 6$
4. **Conv2_1**：$RF = 6 + (3-1) \times 1 = 8$
5. **Conv2_2**：$RF = 8 + (3-1) \times 1 = 10$

**结论**：VGG16 中 Conv2_2 的特征图上 1 个像素对应原图 **10×10** 的区域。

**直觉理解**：经过两次 3×3 卷积（感受野 5）+ 一次池化（扩大 2 倍）+ 两次卷积，总共覆盖 10×10 的原图区域。

## 7. 常见面试问题

### Q1：为什么 CNN 适合处理图像？

**答**：三个关键特性：

1. **局部连接**：每个神经元只连接局部区域，符合图像的局部相关性（相邻像素更相关）
2. **权值共享**：同一个卷积核在整个图像上滑动，大幅减少参数量（相比全连接）
3. **平移不变性**：同一特征在图像不同位置都能被检测到（因为用同一个卷积核）

**对比全连接网络**：
- 全连接：224×224×3 输入 → 1000 输出，参数量 $224 \times 224 \times 3 \times 1000 \approx 150M$
- CNN：3×3 卷积核，64 个核，参数量仅 $3 \times 3 \times 3 \times 64 = 1,728$

### Q2：1×1 卷积的作用是什么？

**答**：1×1 卷积看似奇怪，但有三个重要作用：

1. **降维/升维**：改变通道数，控制模型复杂度（如 Inception 中先降维再卷积）
2. **非线性变换**：1×1 卷积 + ReLU 可以对每个位置的特征进行交叉组合
3. **跨通道信息融合**：在不同通道间做线性组合 + 非线性

**数学本质**：1×1 卷积等价于在**每个空间位置**做一个**全连接层**（通道维度上的 FC）。

### Q3：BatchNorm 放在卷积前还是后？

**答**：有两种主流做法：

**Post-Norm**（传统做法）：Conv → BN → ReLU
- 优点：符合原始 BN 论文设计
- 缺点：BN 作用于卷积输出，可能不是最优

**Pre-Norm**（现代做法）：BN → ReLU → Conv
- 优点：归一化作用于输入，训练更稳定；ReLU 后数据非负，BN 效果更好
- 缺点：最后一个层通常不加 BN+ReLU

**实践建议**：
- 分类任务：Post-Norm（如 ResNet 默认）
- 生成任务（GAN/Diffusion）：Pre-Norm 更稳定
- 差异不大，关键是保持一致性

### Q4：什么是空洞卷积（Dilated Convolution）？有什么作用？

**答**：空洞卷积通过在卷积核元素间插入 0 来**扩大感受野**，而不增加参数量或计算量。

**公式**（1D，dilation rate=$d$）：
$$
(Y *_{d} K)_i = \sum_{k=0}^{k_s-1} K_k \cdot X_{i - d \cdot k}
$$

**示例**（3×3 卷积，dilation=2）：
```
正常卷积：关注 3×3 = 9 个像素
空洞卷积：关注 3×3 但间隔为 2，等效感受野 5×5 = 25 个像素
```

**应用场景**：
- **语义分割**（如 DeepLab 系列）：在不降低分辨率的情况下扩大感受野
- **语音识别**：捕捉长距离依赖
- **时间序列预测**：捕获长期模式

**代价**：感受野内出现"空洞"，可能遗漏信息（可通过多尺度空洞卷积解决）

### Q5：全局平均池化（GAP）相比全连接层有什么好处？

**答**：GAP 是现代 CNN（如 ResNet、EfficientNet）的标准配置，替代了传统的 FC 层：

**优势**：
1. **参数量为 0**：FC 层参数量巨大（如 512×4096=2M），GAP 无参数
2. **防止过拟合**：大幅减少可学习参数
3. **空间信息聚合**：对每个通道的整个特征图做平均，得到通道级描述子
4. **支持变长输入**：FC 要求固定尺寸，GAP 可以接受任意尺寸输入

**实现方式**：
```python
# 输入：(batch, channels=512, height=7, width=7)
x = torch.randn(2, 512, 7, 7)

# 全局平均池化
gap = nn.AdaptiveAvgPool2d(1)  # 输出 1×1
y = gap(x)  # (batch, 512, 1, 1)

# 展平后接分类头
y = y.view(y.size(0), -1)  # (batch, 512)
```

**注意**：GAP 会丢失空间信息，不适合需要定位信息的任务（如目标检测）。

### Q6：深度分离卷积（Depthwise Separable Convolution）是什么？

**答**：MobileNet 的核心创新，将标准卷积拆分为两步：

**标准卷积**：
$$Y = X * K \quad \text{（同时完成空间卷积和通道融合）}$$

**深度分离卷积**：
1. **Depthwise Conv**：每个通道单独做卷积（不跨通道）
2. **Pointwise Conv**：1×1 卷积负责通道融合

**计算量对比**（输入 $C_{in}$ 通道，输出 $C_{out}$ 通道，卷积核 $k \times k$）：

- 标准卷积：$H \cdot W \cdot C_{in} \cdot C_{out} \cdot k^2$
- 深度分离：$H \cdot W \cdot C_{in} \cdot k^2 + H \cdot W \cdot C_{in} \cdot C_{out}$

**压缩比**：
$$
\frac{\text{DepthSep}}{\text{Standard}} = \frac{1}{C_{out}} + \frac{1}{k^2}
$$

当 $C_{out}=256, k=3$ 时，压缩比 $\approx \frac{1}{256} + \frac{1}{9} \approx 0.12$，**减少 88% 计算量**！

**代价**：精度略有下降（但 MobileNetV3 + NAS 可以超越 ResNet）

### Q7：为什么现代 CNN 多用 3×3 卷积而不是 5×5 或 7×7？

**答**：三个原因：

1. **参数效率**：2 个 3×3 串联 = 1 个 5×5 的感受野，但参数更少
   - 2×3×3: $2 \times 3^2 = 18$
   - 1×5×5: $5^2 = 25$
   - **节省 28%**

2. **非线性增强**：2 个 ReLU > 1 个 ReLU，表达能力更强

3. **历史验证**：VGG 证明小卷积核堆叠效果好，后续模型都沿用

**例外**：
- 第一层有时用 7×7（如 ResNet）：一次性捕获较大感受野
- 目标检测中保留部分 5×5：检测大物体

### Q8：CNN 的局限性是什么？

**答**：

1. **平移等变性**：CNN 具有平移等变性（translation equivariance），但不具备旋转/反射不变性（需要数据增强）
2. **局部性限制**：感受野有限，难以建模长距离依赖（Transformer 的优势）
3. **参数共享假设**：假设特征在空间上分布一致，不适用于非均匀特征
4. **归纳偏置过强**：对网格结构有效，但处理图/点云等不规则数据不便

**趋势**：Vision Transformer (ViT) 正在挑战 CNN 的主导地位，但 CNN 在低数据量场景仍有优势。
