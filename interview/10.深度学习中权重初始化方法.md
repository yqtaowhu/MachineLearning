# 深度学习中权重初始化方法

## 1. 概述

**一句话定义**：权重初始化就是在训练开始前，给神经网络每一层的权重矩阵 $W$ 和偏置 $b$ 赋一组"合理的初始值"。

**为什么重要**：初始化方式直接决定了训练初期的前向信号方差和反向梯度方差。初始化不好，轻则收敛慢，重则梯度消失/爆炸，模型根本训不动。好的初始化能让信号在层间"无损传播"，是深层网络能训练的前提之一。

> 直觉：把一叠权重想象成一排传话筒。如果每个人声音都放大一点（方差 > 1），传到后面就炸了（梯度爆炸）；如果每个人都小声一点（方差 < 1），传到后面就听不见了（梯度消失）。好的初始化就是让每个人"正常说话"——方差刚好为 1。

## 2. 常见初始化方法

### 2.1 零初始化 / 常数初始化

**做法**：把所有权重设为同一个常数（通常是 0）。

$$W_{ij} = 0$$

**问题**：所有神经元输出完全相同 → 反向传播时梯度也完全相同 → 所有神经元学到一样的东西 → **对称性问题**（symmetry problem），网络退化成一条线性路径。

**结论**：**绝对不能用于权重矩阵**。偏置 $b$ 可以初始化为 0（因为偏置不参与"对称性"问题）。

> 唯一例外：当使用 BatchNorm 时，某些 BN 的缩放参数 $\gamma$ 初始化为 1、偏移参数 $\beta$ 初始化为 0，这是设计上的特殊选择。

### 2.2 随机初始化（Xavier/Glorot 初始化）

**核心思想**：让每一层输出的方差尽量保持一致，既不让信号放大也不让信号缩小。

**推导直觉**：假设输入 $x$ 和权重 $W$ 都均值为 0，且互相独立，对于一层线性变换 $z = \sum_{i=1}^{n_{in}} w_i x_i$：

$$\text{Var}(z) = n_{in} \cdot \text{Var}(w) \cdot \text{Var}(x)$$

为了让 $\text{Var}(z) = \text{Var}(x)$，需要：

$$\text{Var}(w) = \frac{1}{n_{in}}$$

考虑到反向传播也需要方差稳定，Xavier 取输入和输出维度的调和平均：

$$\text{Var}(w) = \frac{2}{n_{in} + n_{out}}$$

**两种形式**：

| 形式 | 公式 | 适用场景 |
|------|------|----------|
| 正态分布 | $W \sim \mathcal{N}\left(0,\; \frac{2}{n_{in}+n_{out}}\right)$ | 通用 |
| 均匀分布 | $W \sim U\left[-\sqrt{\frac{6}{n_{in}+n_{out}}},\; \sqrt{\frac{6}{n_{in}+n_{out}}}\right]$ | 通用 |

**适用激活函数**：`tanh`、`sigmoid` 等对称/饱和激活函数。

> 记忆口诀：Xavier 的方差 = $\frac{2}{n_{in}+n_{out}}$，"2 除以两边之和"。

### 2.3 He 初始化（Kaiming 初始化）

**核心思想**：针对 ReLU 系列激活函数改进的初始化。

**为什么需要改进**：ReLU 会把负数部分截断为 0，相当于"丢掉了一半"的信号。这导致经过 ReLU 后方差缩小为原来的一半：

$$\text{Var}(\text{ReLU}(z)) = \frac{1}{2}\text{Var}(z)$$

所以需要在 Xavier 的基础上补偿这个 1/2 的损失：

$$\text{Var}(w) = \frac{2}{n_{in}}$$

**两种形式**：

| 形式 | 公式 | 说明 |
|------|------|------|
| 正态分布 | $W \sim \mathcal{N}\left(0,\; \frac{2}{n_{in}}\right)$ | 最常用 |
| 均匀分布 | $W \sim U\left[-\sqrt{\frac{6}{n_{in}}},\; \sqrt{\frac{6}{n_{in}}}\right]$ | 等价形式 |

**适用激活函数**：`ReLU`、`LeakyReLU`、`PReLU`。

> 对于 LeakyReLU（负半轴斜率为 $\alpha$），方差修正为 $\text{Var}(w) = \frac{2}{(1+\alpha^2) \cdot n_{in}}$，当 $\alpha$ 很小时退化为 He 初始化。

### 2.4 正交初始化（Orthogonal Initialization）

**做法**：初始化权重矩阵为正交矩阵，即 $W^T W = I$。

**生成方法**：先生成一个随机矩阵，然后做 QR 分解或 SVD 分解，取正交部分。

**优点**：
- 正交矩阵不改变向量的 L2 范数，因此前向传播时信号范数不变
- 梯度在反向传播时也不会缩放
- 特别适合 RNN/LSTM，因为 RNN 的时序展开相当于非常深的网络

**缺点**：计算成本比 Xavier/He 高（需要做矩阵分解）。

### 2.5 稀疏初始化（Sparse Initialization）

**做法**：每一列（对应一个输出神经元）只有 $k$ 个非零元素（如 $k=15$），其余为 0。非零元素从 $\mathcal{N}(0, 1)$ 中采样。

**优点**：每个神经元只与输入的少数特征相连，打破了对称性，同时避免了全连接带来的方差问题。

**适用场景**：早期深度网络研究、自编码器等。

### 2.6 LSUV 初始化

**全称**：Layer-Sequential Unit-Variance Initialization

**做法**：逐层初始化，每层做两步：
1. 先用正交初始化生成权重矩阵
2. 跑一批数据通过该层，根据实际输出的方差进行缩放，使输出方差恰好为 1

**优点**：不依赖理论假设，直接根据数据调整，适合非常深的网络或特殊结构。

**缺点**：需要额外的前向传播计算，实现较复杂。

## 3. 各方法对比总结

| 方法 | 方差公式 | 适用激活函数 | 计算开销 | 典型场景 |
|------|----------|-------------|----------|----------|
| 零初始化 | 0 | — | 无 | ❌ 不可用 |
| Xavier/Glorot | $\frac{2}{n_{in}+n_{out}}$ | tanh, sigmoid | 极低 | 浅层网络、tanh 激活 |
| He/Kaiming | $\frac{2}{n_{in}}$ | ReLU 系列 | 极低 | CNN、ReLU 网络（**最常用**） |
| 正交初始化 | 保持范数 | 通用 | 中等 | RNN/LSTM |
| 稀疏初始化 | 局部连接 | 通用 | 低 | 特殊架构 |
| LSUV | 数据驱动 = 1 | 通用 | 较高 | 极深网络、特殊结构 |

## 4. 如何选择初始化方法

**实用决策树**：

```
你的网络用了什么激活函数？
├── ReLU / LeakyReLU / PReLU → He 初始化（最常用，默认选择）
├── tanh / sigmoid → Xavier 初始化
├── 是 RNN / LSTM / GRU？ → 正交初始化
└── 网络极深（>50层）或有特殊结构？ → 考虑 LSUV 或直接用 He + BatchNorm
```

**实际工程经验**：
1. **默认选 He 初始化**：现代深度学习绝大多数用 ReLU 系列，He 初始化是安全默认值
2. **PyTorch 默认值**：`nn.Linear` 默认用 Kaiming uniform（$U(-\sqrt{1/n_{in}}, \sqrt{1/n_{in}})$），`nn.Conv2d` 同理
3. **Transformer 中**：通常用小范围正态分布初始化（如 $\sigma = 0.02$），配合 LayerNorm 使用
4. **配合 BatchNorm/LayerNorm**：有归一化层时，初始化的重要性降低，但好的初始化仍能加速收敛

## 5. 与其他概念的关系

| 关联概念 | 关系说明 |
|----------|----------|
| **梯度消失/爆炸** | 初始化不当是梯度消失/爆炸的直接原因之一 |
| **BatchNorm / LayerNorm** | 归一化层可以缓解初始化不当的问题，但不能完全替代好的初始化 |
| **激活函数** | 不同激活函数对应不同的初始化方案（Xavier↔tanh，He↔ReLU） |
| **残差连接（ResNet）** | Skip connection 让信号可以"绕过"某一层，大大降低了对初始化的敏感度 |
| **学习率 warmup** | 训练初期用较小学习率逐步增大，与好的初始化配合可以避免初期不稳定 |

## 6. 具体例子

### 例子 1：Xavier 初始化手算

**问题**：一个全连接层，输入维度 $n_{in} = 256$，输出维度 $n_{out} = 128$，使用 tanh 激活函数，求 Xavier 均匀分布的范围。

**步骤**：

1. 计算方差：$\text{Var}(w) = \frac{2}{n_{in} + n_{out}} = \frac{2}{256 + 128} = \frac{2}{384} \approx 0.00521$

2. 均匀分布范围：$W \sim U\left[-\sqrt{\frac{6}{384}},\; \sqrt{\frac{6}{384}}\right]$

3. 计算边界：$\sqrt{\frac{6}{384}} = \sqrt{0.015625} = 0.125$

**结果**：权重从 $U[-0.125, 0.125]$ 中采样。

**解读**：如果错误地用了 He 初始化，方差会变成 $\frac{2}{256} = 0.00781$，范围变成 $[-0.153, 0.153]$，权重偏大，经过 tanh 后容易进入饱和区，导致梯度消失。

### 例子 2：He 初始化在 CNN 中的应用

**问题**：一个 Conv2d 层，输入通道 $C_{in} = 64$，输出通道 $C_{out} = 128$，卷积核 $3 \times 3$，使用 ReLU。求 He 正态初始化的标准差。

**步骤**：

1. 计算"扇入"（fan_in）：$n_{in} = C_{in} \times k_h \times k_w = 64 \times 3 \times 3 = 576$

2. He 正态初始化标准差：$\sigma = \sqrt{\frac{2}{n_{in}}} = \sqrt{\frac{2}{576}} = \sqrt{0.00347} \approx 0.0589$

**结果**：$W \sim \mathcal{N}(0, 0.0589^2)$，即权重从均值 0、标准差约 0.059 的正态分布中采样。

**解读**：如果错误地用了 Xavier 初始化（假设 $n_{out} = 128 \times 3 \times 3 = 1152$），方差会变成 $\frac{2}{576+1152} = 0.00116$，标准差仅 0.034，权重偏小。经过 ReLU 后方差进一步减半，信号会越来越弱，深层卷积层几乎无法训练。

### 例子 3：PyTorch 代码验证

```python
import torch
import torch.nn as nn

# He 初始化（Kaiming normal）
linear = nn.Linear(256, 128)
# 默认初始化就是 kaiming uniform，这里手动改为 kaiming normal
nn.init.kaiming_normal_(linear.weight, mode='fan_in', nonlinearity='relu')
# weight shape: (128, 256)，即 (out_features, in_features)

print(f"权重均值: {linear.weight.mean():.6f}")   # 接近 0
print(f"权重标准差: {linear.weight.std():.6f}")   # 接近 sqrt(2/256) ≈ 0.0884
print(f"理论标准差: {(2/256)**0.5:.6f}")          # 0.088388

# Xavier 初始化
linear2 = nn.Linear(256, 128)
nn.init.xavier_normal_(linear2.weight)
print(f"Xavier 标准差: {linear2.weight.std():.6f}")  # 接近 sqrt(2/384) ≈ 0.0722
print(f"理论标准差: {(2/384)**0.5:.6f}")              # 0.072169
```

## 7. 常见面试问题

### Q1：为什么神经网络的权重不能全部初始化为 0？

**答案**：如果所有权重相同（比如全 0），那么同一层的每个神经元接收到的加权输入完全一样，反向传播时得到的梯度也完全一样。这意味着所有神经元会同步更新，学到完全相同的特征——这就是**对称性问题**。网络中有 1000 个神经元和 1 个神经元没有区别。随机初始化的目的就是打破这种对称性，让每个神经元从不同的方向开始学习。

### Q2：Xavier 初始化的推导思路是什么？

**答案**：核心目标是让每一层输出的方差等于输入的方差（方差一致性）。对于 $z = \sum w_i x_i$，假设 $w$ 和 $x$ 独立且均值为 0，则 $\text{Var}(z) = n_{in} \cdot \text{Var}(w) \cdot \text{Var}(x)$。令 $\text{Var}(z) = \text{Var}(x)$ 得 $\text{Var}(w) = 1/n_{in}$。再考虑反向传播方向也需要方差稳定，取前向和反向的折中，得到 $\text{Var}(w) = 2/(n_{in}+n_{out})$。

### Q3：为什么 ReLU 网络要用 He 初始化而不是 Xavier？

**答案**：ReLU 会将负值截断为 0，相当于随机丢掉了一半的激活值。数学上，如果输入是均值为 0 的对称分布，经过 ReLU 后方差变为原来的一半：$\text{Var}(\text{ReLU}(z)) = \frac{1}{2}\text{Var}(z)$。Xavier 初始化没有考虑这个 1/2 的缩放，会导致每过一层信号方差就减半，层数多了信号就消失了。He 初始化把方差放大 2 倍来补偿这个损失：$\text{Var}(w) = 2/n_{in}$。

### Q4：偏置 $b$ 需要精心初始化吗？

**答案**：不需要。偏置 $b$ 通常初始化为 0 即可。原因：(1) 偏置不参与对称性问题——即使 $b$ 全为 0，只要 $W$ 是随机的，不同神经元的输出就不同；(2) 偏置只是一个平移量，不影响梯度的缩放行为；(3) 训练几步之后偏置就会自动学到合适的值。

### Q5：BatchNorm 能替代好的初始化吗？

**答案**：不能完全替代，但能大幅缓解。BatchNorm 通过对每层输出做归一化，使得中间层的信号分布相对稳定，降低了对初始化的敏感度。但实验表明，即使有 BatchNorm，使用 He/Xavier 初始化仍然比随机大/小初始化收敛更快。原因：(1) BN 的 $\gamma$、$\beta$ 参数本身也需要合理初始化；(2) 第一层没有 BN 的输入归一化；(3) 好的初始化减少了 BN 需要"纠正"的幅度，训练更稳定。

### Q6：Transformer 为什么不用 He 初始化，而用小范围正态分布（如 $\sigma=0.02$）？

**答案**：Transformer 使用 LayerNorm 和残差连接，信号传播机制与纯前馈网络不同。残差连接保证了梯度可以直接跳过任意层，对初始化不敏感。小范围初始化（如 $\sigma=0.02$）的目的是让残差分支的初始输出尽量小（接近 0），使得训练初期网络行为接近恒等映射 $F(x) \approx x$，这与 ResNet 的设计理念一致。如果用 He 初始化，初始权重较大，残差分支的输出会"淹没"主路径信号，导致训练初期不稳定。

### Q7：RNN 为什么推荐正交初始化？

**答案**：RNN 在时间维度上展开后等价于一个非常深的网络（步数 = 序列长度），同样的权重被反复使用。如果权重的谱半径（最大奇异值）大于 1，梯度会指数级增长（爆炸）；小于 1 则指数级衰减（消失）。正交矩阵的所有奇异值都恰好为 1，因此前向和反向传播时信号范数不变，从根本上解决了 RNN 的梯度问题。对于 LSTM/GRU，虽然门控机制本身缓解了梯度消失，但正交初始化仍然有助于训练稳定性。

### Q8：fan_in 和 fan_out 在卷积层中怎么计算？

**答案**：对于卷积层 $\text{Conv2d}(C_{in}, C_{out}, k_h \times k_w)$：
- $\text{fan\_in} = C_{in} \times k_h \times k_w$（每个输出神经元连接的输入元素个数）
- $\text{fan\_out} = C_{out} \times k_h \times k_w$

注意不是 $C_{in} \times H \times W$（那不是单个神经元的感觉野）。PyTorch 中 `nn.init.calculate_gain(nonlinearity)` 可以自动计算对应激活函数的增益系数。

### Q9：初始化方法对模型最终精度影响大吗？

**答案**：对最终精度影响不大，但对**收敛速度**和**训练稳定性**影响很大。好的初始化让模型在前几个 epoch 就能快速下降，差的初始化可能需要几十个 epoch 才能"找到方向"，甚至直接卡在损失曲线上不动。在极端情况下（非常深的网络、没有归一化层），错误的初始化会导致模型完全无法训练。实际工程中，好的初始化 + 合适的学习率策略 = 训练效率翻倍。

### Q10：如果不确定该用什么初始化，最安全的默认选择是什么？

**答案**：**He 初始化（Kaiming normal，mode='fan_in'）**。理由：(1) 现代网络绝大多数使用 ReLU 系列激活函数；(2) He 初始化在理论和实践中都验证了对 ReLU 网络的最优性；(3) PyTorch 的 `nn.Linear`、`nn.Conv2d` 默认就是 Kaiming 初始化（uniform 版本）；(4) 即使配合 BatchNorm/LayerNorm，He 初始化也是安全且高效的选择。
