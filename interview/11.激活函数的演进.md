# 激活函数的演进：从 ReLU 到 GELU/Swish

## 1. 概述

激活函数的核心任务是给网络引入**非线性**。但不同激活函数对梯度流动、神经元稀疏性、计算效率的影响差异巨大。

**演进的主线逻辑**只有一条：

> 在保留 ReLU "正区间无饱和、计算快"优点的同时，逐步解决三个痛点——**Dead ReLU（负区间永久死亡）**、**负区间信息完全丢弃**、**梯度不够平滑**。

由此产生了从 ReLU → Leaky ReLU → GELU → Swish 的演进路线。GELU 和 Swish 已成为 Transformer（BERT、GPT）和现代 CNN（EfficientNet）的默认选择。

## 2. 演进脉络：每一代在解决什么问题

| 阶段 | 代表 | 核心动机 | 解决了什么 | 遗留问题 |
|------|------|----------|-----------|---------|
| 第一代 | Sigmoid, Tanh | 引入非线性、输出有界 | 理论优美 | 梯度消失、指数运算慢 |
| 第二代 | ReLU | 正区间梯度恒为 1 | 梯度消失、计算快 | 负区间死亡、非零均值 |
| 第三代 | Leaky ReLU, PReLU | 给负区间一个非零斜率 | Dead ReLU | 负区间信息仍被大幅压缩 |
| 第四代 | **GELU** | 用概率"软门控"代替硬阈值 | 平滑 + 随机正则化效果 | 含 erf/tanh，略慢 |
| 第五代 | **Swish/SiLU** | 自门控：让输入自己决定通过比例 | 非单调性提升深层表达力 | 负区间仍有小幅振荡 |
| 同期 | **Mish** | 平滑 + 自正则 | 兼顾 GELU 与 Swish 优点 | 计算量最大 |

一句话总结演进方向：

> **从"硬切"（ReLU 的 max(0,x)）→ "软切"（GELU 的概率门控）→ "自门控"（Swish 让输入自己决定通过多少）。**

## 3. 经典激活函数回顾

### 3.1 Sigmoid / Tanh

$$\sigma(x) = \frac{1}{1+e^{-x}}, \quad \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

- **致命缺陷**：当 $|x|$ 较大时，梯度趋近于 0；多层连乘后梯度消失。
- **非零均值**（Sigmoid）：输出恒为正，导致下一层权重梯度符号一致，训练效率低。
- **指数运算**：在 GPU 上比加减乘慢数倍。

### 3.2 ReLU 及其变体

$$\text{ReLU}(x) = \max(0, x)$$

**优点**：
1. 正区间梯度恒为 1，彻底缓解梯度消失
2. 计算极快：一个 if-else
3. 负值输出为 0 → 稀疏激活，类似隐式 Dropout

**缺点**：
1. **Dead ReLU 问题**：一旦某个神经元输出为负，梯度永远为 0，该神经元"永久死亡"
2. **非零均值**：输出 $\geq 0$，下一层输入偏正
3. **硬拐角**：在 $x=0$ 处不可导，负区间信息完全丢弃

**Leaky ReLU / PReLU** 的改进：

$$\text{Leaky ReLU}(x) = \begin{cases} x, & x > 0 \\ \alpha x, & x \leq 0 \end{cases}$$

给负区间一个很小的固定斜率 $\alpha$（通常 0.01），PReLU 则让 $\alpha$ 可学习。这解决了 Dead ReLU，但负区间信息仍被大幅压缩（只保留了约 1% 的信号）。

## 4. GELU：高斯误差线性单元

> **论文**：Hendrycks & Gimpel, 2016. *Gaussian Error Linear Units (GELUs)*
> **应用**：BERT、GPT 系列、ViT 等几乎所有 Transformer 模型

### 4.1 动机

ReLU 的做法是"硬门控"——$x > 0$ 全通过，$x \leq 0$ 全截断。这很粗暴。

GELU 的核心思想是：**不要用硬阈值，而是用输入值的概率分布来决定通过比例**。

具体来说：假设输入 $x$ 服从某个分布，我们用一个随机门控变量 $m \in \{0, 1\}$ 来决定是否通过，其中 $P(m=1)$ 由 $x$ 本身决定——$x$ 越大，通过概率越高。最终：

$$\text{GELU}(x) = x \cdot P(X \leq x) = x \cdot \Phi(x)$$

其中 $\Phi(x)$ 是标准正态分布的累积分布函数（CDF）。

### 4.2 公式

精确形式：

$$\text{GELU}(x) = x \cdot \Phi(x) = x \cdot \frac{1}{2}\left[1 + \text{erf}\left(\frac{x}{\sqrt{2}}\right)\right]$$

其中 $\text{erf}(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} dt$ 是误差函数。

实际工程中常用两种近似：

**Gaussian 近似**（直接计算 CDF）：
$$\text{GELU}(x) \approx 0.5x\left(1 + \tanh\left[\sqrt{2/\pi}\left(x + 0.044715x^3\right)\right]\right)$$

这是 BERT 和 GPT-2 中使用的版本，计算速度快于精确的 erf。

**快速近似**：
$$\text{GELU}(x) \approx x \cdot \sigma(1.702x)$$

其中 $\sigma$ 是 sigmoid 函数，计算更快，常用于对速度敏感的场景。

### 4.3 直觉理解

把 GELU 想象成一个"概率过滤器"：

| 输入 $x$ | $\Phi(x)$（通过概率） | GELU 输出 | 直觉 |
|----------|---------------------|----------|------|
| $x = 3$ | $\approx 0.999$ | $\approx 3.0$ | 几乎全部通过 |
| $x = 1$ | $\approx 0.841$ | $\approx 0.841$ | 大部分通过 |
| $x = 0$ | $= 0.5$ | $= 0$ | 一半通过，但乘以 0 后恰好为 0 |
| $x = -1$ | $\approx 0.159$ | $\approx -0.159$ | 少量通过，保留了负值信息 |
| $x = -3$ | $\approx 0.001$ | $\approx -0.003$ | 几乎完全截断 |

**与 ReLU 的关键区别**：ReLU 在 $x=0$ 处硬切，而 GELU 在 $x=0$ 附近平滑过渡，负值有小幅非零输出——既保留了负值信息，又提供了类似 Dropout 的正则化效果。

### 4.4 重要性质

1. **平滑可导**：处处可导，没有 ReLU 在 $x=0$ 处的硬拐角
2. **负区间非零**：保留了负值的少量信息（不像 ReLU 直接截断为 0）
3. **非单调**：在 $x \approx -0.85$ 处有一个局部极小值（约 $-0.17$），这意味着更小的输入不一定产生更小的输出——增加了网络的表达能力
4. **正则化效果**：概率门控机制类似 Dropout，有隐式的正则化作用
5. **零中心**：$\text{GELU}(0) = 0$，且负值输出使均值更接近 0

## 5. Swish / SiLU：自门控激活

> **论文**：Ramachandran et al., 2017. *Searching for Activation Functions*（Google Brain 用强化学习搜索得到）
> **应用**：EfficientNet 系列、GPT-J、LLaMA、PaLM 等大语言模型

### 5.1 动机

Google Brain 团队用 NAS（神经架构搜索）在 CIFAR-100 上自动搜索激活函数，发现了一个形式极其简单的函数表现优于 GELU：

$$f(x) = x \cdot \sigma(x)$$

他们将其命名为 **Swish**。其核心创新是**自门控（Self-Gating）**：不是用外部概率（如 GELU 用正态分布 CDF）来决定通过比例，而是**让输入 $x$ 自己通过 sigmoid 产生一个门控值**。

### 5.2 公式

$$\text{Swish}(x) = x \cdot \sigma(\beta x) = \frac{x}{1 + e^{-\beta x}}$$

- 当 $\beta = 1$ 时，称为 **SiLU**（Sigmoid Linear Unit），PyTorch 中 `nn.SiLU()` 即此
- 当 $\beta = 0$ 时，退化为线性函数 $f(x) = x/2$
- 当 $\beta \to \infty$ 时，趋近于 ReLU

**带参数版本**（EfficientNet 使用）：$\beta$ 是可学习参数，网络自动决定门控的"软硬程度"。

### 5.3 直觉理解

Swish 可以理解为：**输入 $x$ 先通过 sigmoid 生成一个 $[0,1]$ 的门控信号，再用这个信号去"缩放"自己**。

| 输入 $x$ | $\sigma(x)$（门控值） | Swish 输出 | 直觉 |
|----------|---------------------|-----------|------|
| $x = 5$ | $\approx 0.993$ | $\approx 4.97$ | 门几乎全开 |
| $x = 1$ | $\approx 0.731$ | $\approx 0.731$ | 门开约 73% |
| $x = 0$ | $= 0.5$ | $= 0$ | 门开一半，但 $x=0$ 所以输出为 0 |
| $x = -1$ | $\approx 0.269$ | $\approx -0.269$ | 门开约 27%，保留负值信息 |
| $x = -5$ | $\approx 0.007$ | $\approx -0.033$ | 门几乎关闭 |

**与 GELU 的对比**：
- GELU 用**外部固定的正态分布**决定门控概率——"先验知识"
- Swish 用**输入自身的 sigmoid**决定门控比例——"自适应"
- 两者形状非常相似，但 Swish 在负区间有一个更深的"凹陷"

### 5.4 重要性质

1. **非单调性**：当 $x$ 从 $-\infty$ 增加到约 $-1.27$ 时，输出先减小再增大——这个"凹陷"让网络能区分绝对值相近但符号不同的输入
2. **无界性**：正值无上界（避免梯度饱和），负值有下界（约 $-0.278$）
3. **平滑可导**：处处无限阶可导
4. **自门控**：不需要额外参数（$\beta=1$ 时），门控信号来自输入本身
5. **实验表现**：在深层网络（>50 层）上，Swish 通常比 ReLU/GELU 提升 0.5-1% 的精度

## 6. Mish：平滑且自正则

> **论文**：Misra, 2019. *Mish: A Self Regularized Non-Monotonic Activation Function*

$$\text{Mish}(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\ln(1 + e^x))$$

Mish 可以看作 Swish 的"软版本"——用 $\tanh(\text{softplus}(x))$ 替代 $\sigma(x)$ 作为门控函数。

**与 Swish 的区别**：
- Mish 的门控函数 $\tanh(\text{softplus}(x))$ 在负区间比 Swish 的 $\sigma(x)$ 更平滑
- Mish 的负区间凹陷更深（约 $-0.31$），保留了更多负值信息
- 计算量略大于 Swish（需要计算 softplus + tanh）

**实验结果**：在 ImageNet 上，Mish 比 ReLU 提升约 1.5%，比 GELU 提升约 0.5%，但与 Swish 差距不大。

## 7. 横向对比

| 特性 | ReLU | GELU | Swish/SiLU | Mish |
|------|------|------|-----------|------|
| 公式 | $\max(0,x)$ | $x\cdot\Phi(x)$ | $x\cdot\sigma(x)$ | $x\cdot\tanh(\ln(1+e^x))$ |
| 平滑性 | ✗（$x=0$ 不可导） | ✓ | ✓ | ✓ |
| 负区间输出 | 0 | 非零（小幅） | 非零（凹陷） | 非零（更深凹陷） |
| 非单调 | ✗ | ✓ | ✓ | ✓ |
| 有界性 | 无上界 | 无上界 | 无上界/有下界 | 无上界/有下界 |
| 计算开销 | 极低 | 中（tanh 或 erf） | 中（sigmoid） | 较高（softplus+tanh） |
| 典型应用 | CNN（ResNet 等） | **Transformer（BERT/GPT）** | **LLM（LLaMA/PaLM）** | 实验性网络 |
| 参数 | 无 | 无 | 可选 $\beta$ | 无 |

**一句话选型建议**：
- 训练 Transformer → 默认 **GELU**
- 训练大语言模型 / EfficientNet → 默认 **Swish/SiLU**
- 追求极致精度且不在乎速度 → 考虑 **Mish**
- 追求速度、网络不深 → **ReLU** 仍然够用

## 8. 具体例子

### 例子 1：用具体数字对比 ReLU、GELU、Swish 的输出

**问题**：给定输入 $x = -1$，分别计算 ReLU、GELU、Swish 的输出，并分析差异。

**步骤**：

**ReLU**：
$$\text{ReLU}(-1) = \max(0, -1) = 0$$

**GELU**（使用近似公式）：
$$\text{GELU}(-1) \approx 0.5 \times (-1) \times \left(1 + \tanh\left[\sqrt{2/\pi}(-1 + 0.044715 \times (-1)^3)\right]\right)$$
$$= -0.5 \times \left(1 + \tanh\left[\sqrt{2/\pi} \times (-1.044715)\right]\right)$$
$$= -0.5 \times \left(1 + \tanh(-0.8324)\right)$$
$$= -0.5 \times (1 + (-0.6824))$$
$$= -0.5 \times 0.3176 \approx -0.159$$

**Swish**（$\beta = 1$）：
$$\text{Swish}(-1) = -1 \times \sigma(-1) = -1 \times \frac{1}{1+e^1} = -1 \times 0.2689 \approx -0.269$$

**结果解读**：
- ReLU 直接输出 0，负值信息完全丢失
- GELU 输出 $-0.159$，保留了约 16% 的原始信号
- Swish 输出 $-0.269$，保留了约 27% 的原始信号，保留信息更多

### 例子 2：为什么非单调性有帮助？

**问题**：假设网络有两个神经元，输入分别为 $x_1 = -2$ 和 $x_2 = -0.5$。用 ReLU 和 Swish 分别计算输出，分析非单调性的作用。

**步骤**：

**ReLU**：
$$\text{ReLU}(-2) = 0, \quad \text{ReLU}(-0.5) = 0$$

两个不同的输入产生了**完全相同**的输出 0，网络无法区分它们。

**Swish**：
$$\text{Swish}(-2) = -2 \times \sigma(-2) = -2 \times 0.1192 \approx -0.238$$
$$\text{Swish}(-0.5) = -0.5 \times \sigma(-0.5) = -0.5 \times 0.3775 \approx -0.189$$

两个输入产生了**不同**的输出（$-0.238$ vs $-0.189$），网络可以区分它们。

更有趣的是，$|x_1| > |x_2|$ 但 $|\text{Swish}(x_1)| > |\text{Swish}(x_2)|$——这正是**非单调性**的体现：在负区间，更小的输入反而产生更大的输出绝对值。这种"反直觉"的行为增加了网络的表达能力，使其能学到更复杂的模式。

**结果解读**：非单调性让网络在负值区域也能区分不同量级的输入，而 ReLU 把所有负值"一视同仁"地映射为 0，丧失了区分能力。

## 9. 常见面试问题

### Q1：ReLU 有什么缺点？GELU/Swish 是如何解决这些缺点的？

**答**：

ReLU 的三个主要缺点及解决方案：

| ReLU 缺点 | GELU 的解决方式 | Swish 的解决方式 |
|-----------|---------------|----------------|
| $x=0$ 处不可导（硬拐角） | 用 $\Phi(x)$ 平滑过渡 | 用 $\sigma(x)$ 平滑过渡 |
| 负区间输出恒为 0（Dead ReLU） | 负区间有非零输出 | 负区间有非零输出（凹陷） |
| 负值信息完全丢失 | 保留约 16% 的负值信号 | 保留约 27% 的负值信号 |

核心改进思路一致：**用平滑的概率函数替代硬阈值，让负值也能以一定比例通过**。

### Q2：GELU 和 Swish 的核心区别是什么？

**答**：

两者的公式结构都是 $f(x) = x \cdot \text{gate}(x)$，区别在于**门控信号从哪里来**：

- **GELU**：$\text{gate}(x) = \Phi(x)$，门控概率由**标准正态分布的 CDF** 决定——这是一个固定的、基于先验知识的概率
- **Swish**：$\text{gate}(x) = \sigma(x)$，门控值由**输入自身的 sigmoid** 决定——这是一个自适应的、数据驱动的门控

直觉上：GELU 是"外部裁判"（固定分布）决定通过比例，Swish 是"自己决定"（自门控）。实验中 Swish 在深层网络上通常略优于 GELU。

### Q3：为什么 Swish 被称为"自门控"激活函数？

**答**：

传统门控机制（如 LSTM 的门）是用**另一个变换**产生门控信号。而 Swish 的门控信号 $\sigma(x)$ 直接来自**输入 $x$ 自身**：

$$\text{Swish}(x) = x \cdot \underbrace{\sigma(x)}_{\text{自门控信号}}$$

- 当 $x$ 很大时，$\sigma(x) \to 1$，输出 $\approx x$（门全开）
- 当 $x$ 很小时，$\sigma(x) \to 0$，输出 $\approx 0$（门关闭）
- 当 $x$ 为负时，$\sigma(x) < 0.5$，输出被缩小但不为 0

这种"自己控制自己通过多少"的机制就是**自门控（Self-Gating）**。

### Q4：什么是激活函数的"非单调性"？为什么它有帮助？

**答**：

单调性意味着：$x_1 > x_2 \Rightarrow f(x_1) > f(x_2)$。ReLU、Sigmoid、Tanh 都是单调的。

**非单调**意味着：存在 $x_1 > x_2$ 但 $f(x_1) < f(x_2)$ 的情况。GELU 和 Swish 在负区间都是非单调的。

**为什么有帮助**：
1. **增加表达能力**：网络可以区分绝对值相近但不同的负值输入
2. **更丰富的梯度信号**：非单调区域的梯度方向变化，有助于跳出局部最优
3. **类似正则化**：非单调映射使得网络不容易对所有负值给出相同响应

### Q5：SiLU 和 Swish 是什么关系？

**答**：

**完全相同**。SiLU（Sigmoid Linear Unit）就是 $\beta = 1$ 时的 Swish：

$$\text{SiLU}(x) = x \cdot \sigma(x) = \text{Swish}_{\beta=1}(x)$$

- PyTorch 中叫 `nn.SiLU()`
- 论文中叫 Swish
- 两者公式完全一样，只是命名来源不同

SiLU 这个名字更早出现在数学文献中，Swish 是 Google Brain 在 NAS 搜索中重新发现并命名的。

### Q6：为什么 Transformer 模型普遍选择 GELU 而不是 ReLU？

**答**：

Transformer 选择 GELU 有三个关键原因：

1. **平滑性**：Transformer 层数深（BERT 12/24 层，GPT-3 96 层），ReLU 在 $x=0$ 处的硬拐角会导致梯度不稳定，GELU 处处平滑
2. **负值信息保留**：Self-Attention 产生的 QKV 点积结果有正有负，GELU 保留负值信息，避免信息损失
3. **正则化效果**：GELU 的概率门控机制类似 Dropout，对大规模预训练模型有隐式正则化作用，减少过拟合

实验数据：在 BERT 论文中，GELU 比 ReLU 在 GLUE benchmark 上提升约 0.3-0.5%。

### Q7：为什么 LLaMA 等现代大模型用 Swish 而不是 GELU？

**答**：

现代大语言模型（LLaMA、PaLM、GPT-J）倾向使用 Swish/SiLU 的原因：

1. **实验更优**：Google 在 PaLM 论文中报告 SiLU 比 GELU 在相同参数量下 perplexity 低约 0.5-1%
2. **计算效率**：Swish 的 $\sigma(x)$ 比 GELU 的 $\tanh$ 近似更快（sigmoid 有专门的硬件优化）
3. **非单调性更强**：Swish 在负区间的凹陷更深，表达能力更强
4. **RMSNorm 配合**：现代模型用 RMSNorm 替代 LayerNorm，与 Swish 的无界特性更匹配

不过差距不大，GELU 仍然是可接受的选择。

### Q8：Swish 中的参数 $\beta$ 有什么作用？训练时怎么设置？

**答**：

$$\text{Swish}_\beta(x) = x \cdot \sigma(\beta x)$$

$\beta$ 控制门控的"软硬程度"：
- $\beta = 0$：退化为线性 $f(x) = x/2$
- $\beta = 1$：标准 Swish/SiLU
- $\beta \to \infty$：趋近于 ReLU

**训练策略**：
- **固定 $\beta = 1$**：最常用，PyTorch 的 `nn.SiLU()` 就是这样，简单有效
- **可学习 $\beta$**：EfficientNet 中使用，将 $\beta$ 作为每个 batch norm 层之后的可学习参数，不同层学到不同的 $\beta$ 值（实验发现浅层 $\beta$ 较大、深层 $\beta$ 较小）

### Q9：从信息论角度，如何理解 GELU 和 Swish 比 ReLU 更优？

**答**：

从信息论角度看，激活函数是一个"信息通道"：

- **ReLU**：负值信息完全丢失，相当于对负半轴做了"硬截断"，信息损失最大
- **GELU**：负值以概率 $\Phi(x)$ 通过，信息损失较小；概率门控类似加性噪声，有正则化效果
- **Swish**：负值以 $\sigma(x)$ 比例通过，且非单调性使得不同负值产生不同输出，信息保留最多

用互信息（Mutual Information）来衡量：$\text{MI}(X; f(X))$ 越大，保留的输入信息越多。实验表明 $\text{MI}_{\text{Swish}} > \text{MI}_{\text{GELU}} > \text{MI}_{\text{ReLU}}$，这与它们的实验性能排序一致。

### Q10：如果你在训练一个 100 层的 Transformer，你会选什么激活函数？为什么？

**答**：

我会选择 **Swish/SiLU**，理由如下：

1. **100 层网络对平滑性要求极高**：Swish 处处无限阶可导，梯度传播最稳定
2. **深层网络需要更强的表达能力**：Swish 的非单调性在深层网络中优势更明显
3. **计算效率**：Swish 的 sigmoid 计算比 GELU 的 tanh 近似更快，100 层累积下来差异显著
4. **实证支持**：PaLM（540B 参数、118 层）使用 Swish 取得了优异效果

如果追求与现有代码/权重的兼容性，GELU 也是很好的选择——两者性能差距通常在 1% 以内。
