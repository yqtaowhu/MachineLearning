# Transformer PyTorch 细节实现

> 本文基于论文 *"Attention Is All You Need"* (Vaswani et al., 2017)，用 PyTorch 从零实现 Transformer 的每一个组件，并在每个模块上标注**维度变化**和**面试常考点**。

---

## 1. 整体架构

Transformer 采用 **Encoder-Decoder** 结构：

- **Encoder**：N 层相同的 Layer 堆叠，每层包含 Multi-Head Self-Attention + FFN，每个子层后都有残差连接 + LayerNorm。
- **Decoder**：N 层相同的 Layer 堆叠，每层多一个 Masked Multi-Head Attention（对 decoder 输入做 self-attention 时加 mask，防止看到未来信息），以及一个 Cross-Attention（Q 来自 decoder，K/V 来自 encoder 输出）。

```
输入文本 → [Token Embed + Positional Encoding] → Encoder × N → 编码器输出
                                                    ↑ K, V
输出文本 → [Token Embed + Positional Encoding] → Decoder × N → Linear + Softmax → 预测概率
                     ↑ Q                         ↑ Masked Self-Attn + Cross-Attn + FFN
```

---

## 2. 输入表示：Token Embedding + Positional Encoding

### 2.1 Token Embedding

将 token id 映射为 $d_{model}$ 维向量，并乘以 $\sqrt{d_{model}}$ 进行缩放。

```python
import torch
import torch.nn as nn
import math

class TokenEmbedding(nn.Module):
    """Token Embedding 层"""
    def __init__(self, vocab_size: int, d_model: int):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)
        self.d_model = d_model

    def forward(self, x):
        # x: (batch, seq_len) → embed: (batch, seq_len, d_model)
        return self.embed(x) * math.sqrt(self.d_model)
```

### 2.2 Positional Encoding

用正弦/余弦函数生成位置编码，不同维度使用不同频率的正弦波：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

- $pos$：token 在序列中的位置（0, 1, 2, ...）
- $i$：维度索引（0, 1, 2, ..., $d_{model}/2 - 1$）

**为什么用 sin/cos？** 对于任意固定偏移量 $k$，$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性函数，这意味着模型可以学习到相对位置关系。

```python
class PositionalEncoding(nn.Module):
    """Positional Encoding 层"""
    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)

        # 预计算位置编码矩阵 (max_len, d_model)
        pe = torch.zeros(max_len, d_model)           # (max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()  # (max_len, 1)
        # div_term: exp(-log(10000) * 2i / d_model) = 1 / 10000^(2i/d_model)
        div_term = torch.exp(
            torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model)
        )  # (d_model/2,)
        pe[:, 0::2] = torch.sin(position * div_term)  # 偶数维度: sin
        pe[:, 1::2] = torch.cos(position * div_term)  # 奇数维度: cos
        pe = pe.unsqueeze(0)  # (1, max_len, d_model)，方便广播到 batch 维度
        self.register_buffer('pe', pe)  # 注册为 buffer，不参与梯度更新

    def forward(self, x):
        # x: (batch, seq_len, d_model)
        x = x + self.pe[:, :x.size(1), :]
        return self.dropout(x)
```

**面试点**：
- 为什么位置编码用 sin/cos 而不是直接学？→ 泛化到任意长度、相对位置可线性表达、不需要训练参数。
- 为什么偶数维度用 sin、奇数维度用 cos？→ 同一位置 $pos$ 的第 $i$ 对 (sin, cos) 构成一个旋转，便于模型学习相对位置。

## 3. Scaled Dot-Product Attention

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- $Q$ (Query)、$K$ (Key)、$V$ (Value) 都是矩阵
- $\sqrt{d_k}$ 缩放因子：防止点积值过大导致 softmax 进入梯度极小的饱和区

```python
def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Q: (batch, heads, seq_q, d_k)
    K: (batch, heads, seq_k, d_k)
    V: (batch, heads, seq_k, d_v)
    mask: 可选, 用于 padding mask 或 look-ahead mask
    返回: (batch, heads, seq_q, d_v)
    """
    d_k = Q.size(-1)

    # 1. 计算注意力分数: (batch, heads, seq_q, d_k) @ (batch, heads, d_k, seq_k)
    #    → (batch, heads, seq_q, seq_k)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

    # 2. 如果有 mask，将 mask=0 的位置设为 -inf
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))

    # 3. softmax 归一化
    attn_weights = torch.softmax(scores, dim=-1)  # (batch, heads, seq_q, seq_k)

    # 4. 加权求和: (batch, heads, seq_q, seq_k) @ (batch, heads, seq_k, d_v)
    #    → (batch, heads, seq_q, d_v)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights
```

**面试点**：
- 为什么要除以 $\sqrt{d_k}$？→ 假设 $Q$、$K$ 各元素独立标准正态，点积 $q \cdot k$ 的方差为 $d_k$，除以 $\sqrt{d_k}$ 使方差回到 1，避免 softmax 饱和。
- Attention 的时间复杂度？→ $O(n^2 \cdot d)$，其中 $n$ 是序列长度，$d$ 是维度，瓶颈在 $QK^T$ 的矩阵乘法。

## 4. Multi-Head Attention

将 $d_{model}$ 分成 $h$ 个头，每个头维度 $d_k = d_{model} / h$，各自独立做 Scaled Dot-Product Attention，然后拼接结果再做一次线性变换。

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O$$

$$\text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

```python
class MultiHeadAttention(nn.Module):
    """多头注意力机制"""
    def __init__(self, d_model: int, n_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads  # 每个头的维度

        # 四个线性变换: Q, K, V 的投影 + 输出投影
        self.W_q = nn.Linear(d_model, d_model)  # (d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        self.dropout = nn.Dropout(p=dropout)

    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)

        # 1. 线性投影并分头
        # Q: (batch, seq_q, d_model) → (batch, seq_q, d_model) → (batch, seq_q, n_heads, d_k)
        #    → (batch, n_heads, seq_q, d_k)
        Q = self.W_q(Q).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(K).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(V).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)

        # 2. Scaled Dot-Product Attention
        attn_output, attn_weights = scaled_dot_product_attention(Q, K, V, mask)
        # attn_output: (batch, n_heads, seq_q, d_k)

        # 3. 拼接所有头
        # (batch, n_heads, seq_q, d_k) → (batch, seq_q, n_heads, d_k) → (batch, seq_q, d_model)
        attn_output = attn_output.transpose(1, 2).contiguous() \
            .view(batch_size, -1, self.d_model)

        # 4. 最终线性变换
        output = self.W_o(attn_output)  # (batch, seq_q, d_model)
        return self.dropout(output), attn_weights
```

**面试点**：
- 多头的好处？→ 允许模型在不同的表示子空间中关注不同位置的信息，类似 CNN 的多核滤波器。参数量与单头相当（因为每个头的维度缩小了）。
- 10×64 的输入，8 头 Multi-Head Attention，参数量？

  **逐步拆解**：输入形状 `(batch=10, seq_len, d_model=64)`，8 个头，每个头 $d_k = 64/8 = 8$。

  Multi-Head Attention 包含 4 个 `nn.Linear(d_model, d_model)` 即 `nn.Linear(64, 64)`：

  | 参数矩阵 | 权重 (weight) | 偏置 (bias) | 小计 |
  |---------|-------------|------------|------|
  | $W^Q$ | $64 \times 64 = 4096$ | $64$ | $4160$ |
  | $W^K$ | $64 \times 64 = 4096$ | $64$ | $4160$ |
  | $W^V$ | $64 \times 64 = 4096$ | $64$ | $4160$ |
  | $W^O$ | $64 \times 64 = 4096$ | $64$ | $4160$ |
  | **合计** | | | **16640** |

  计算公式：$4 \times (64 \times 64 + 64) = 4 \times 4160 = 16640$

  **关键结论**：多头注意力的参数量与单头相同（都是 $4 \times d_{model}^2 + 4 \times d_{model}$），多头只是把 $d_{model}$ 切分成多个子空间，总维度不变，所以参数量不增加。

## 5. Position-wise Feed-Forward Network

对每个位置独立做相同的两层全连接网络：

$$\text{FFN}(x) = \max(0, x W_1 + b_1) W_2 + b_2$$

内部维度 $d_{ff} = 2048$（通常 $4 \times d_{model}$）。

```python
class PositionwiseFeedForward(nn.Module):
    """逐位置前馈网络"""
    def __init__(self, d_model: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.linear1 = nn.Linear(d_model, d_ff)   # (d_model, d_ff)
        self.linear2 = nn.Linear(d_ff, d_model)    # (d_ff, d_model)
        self.dropout = nn.Dropout(p=dropout)
        self.relu = nn.ReLU()

    def forward(self, x):
        # x: (batch, seq_len, d_model)
        # → (batch, seq_len, d_ff) → relu → (batch, seq_len, d_ff)
        # → (batch, seq_len, d_model)
        return self.linear2(self.dropout(self.relu(self.linear1(x))))
```

**面试点**：
- 为什么叫 "Position-wise"？→ 对序列中每个位置独立做相同的全连接，不同位置共享参数但互不干扰。
- FFN 的参数量？→ $d_{model} \times d_{ff} + d_{ff} + d_{ff} \times d_{model} + d_{model}$，当 $d_{model}=512, d_{ff}=2048$ 时约 210 万。

## 6. Add & Norm（残差连接 + 层归一化）

每个子层（Attention / FFN）的输出都经过：

$$\text{output} = \text{LayerNorm}(x + \text{SubLayer}(x))$$

残差连接缓解深层网络的梯度消失；LayerNorm 稳定训练。

```python
class AddAndNorm(nn.Module):
    """残差连接 + LayerNorm"""
    def __init__(self, d_model: int, dropout: float = 0.1):
        super().__init__()
        self.norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(p=dropout)

    def forward(self, x, sublayer_output):
        # x: 子层输入 (batch, seq_len, d_model)
        # sublayer_output: 子层输出 (batch, seq_len, d_model)
        return self.norm(x + self.dropout(sublayer_output))
```

**面试点**：
- 为什么用 LayerNorm 而不是 BatchNorm？→ NLP 中序列长度不固定，BatchNorm 在 seq 维度做归一化会跨不同长度的位置，效果差；LayerNorm 在每个样本内部做归一化，不受 batch 和序列长度影响。
- Pre-Norm vs Post-Norm？→ 原始 Transformer 用 Post-Norm（先子层再 Norm），但 Pre-Norm（先 Norm 再子层）训练更稳定，是目前主流做法。

## 7. Encoder Layer

一个 Encoder Layer = Multi-Head Self-Attention + Add&Norm + FFN + Add&Norm

```python
class EncoderLayer(nn.Module):
    """单个 Encoder 层"""
    def __init__(self, d_model: int, n_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ffn = PositionwiseFeedForward(d_model, d_ff, dropout)
        self.add_norm1 = AddAndNorm(d_model, dropout)
        self.add_norm2 = AddAndNorm(d_model, dropout)

    def forward(self, x, src_mask=None):
        # x: (batch, seq_len, d_model)
        # 子层1: Multi-Head Self-Attention
        attn_output, _ = self.self_attn(x, x, x, src_mask)  # Q=K=V=x (self-attention)
        x = self.add_norm1(x, attn_output)

        # 子层2: Position-wise FFN
        ffn_output = self.ffn(x)
        x = self.add_norm2(x, ffn_output)
        return x  # (batch, seq_len, d_model)
```

## 8. Decoder Layer

一个 Decoder Layer = Masked Multi-Head Self-Attention + Add&Norm + Multi-Head Cross-Attention + Add&Norm + FFN + Add&Norm

```python
class DecoderLayer(nn.Module):
    """单个 Decoder 层"""
    def __init__(self, d_model: int, n_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ffn = PositionwiseFeedForward(d_model, d_ff, dropout)
        self.add_norm1 = AddAndNorm(d_model, dropout)
        self.add_norm2 = AddAndNorm(d_model, dropout)
        self.add_norm3 = AddAndNorm(d_model, dropout)

    def forward(self, x, encoder_output, src_mask=None, tgt_mask=None):
        # x: (batch, tgt_len, d_model)
        # encoder_output: (batch, src_len, d_model)

        # 子层1: Masked Multi-Head Self-Attention (防止看到未来 token)
        attn_output, _ = self.self_attn(x, x, x, tgt_mask)  # Q=K=V=x
        x = self.add_norm1(x, attn_output)

        # 子层2: Cross-Attention (Q 来自 decoder, K/V 来自 encoder)
        cross_output, _ = self.cross_attn(x, encoder_output, encoder_output, src_mask)
        x = self.add_norm2(x, cross_output)

        # 子层3: Position-wise FFN
        ffn_output = self.ffn(x)
        x = self.add_norm3(x, ffn_output)
        return x  # (batch, tgt_len, d_model)
```

**面试点**：
- Decoder 中为什么需要两种 Attention？→ Masked Self-Attention 让 decoder 只能看到已生成的 token（自回归）；Cross-Attention 让 decoder 利用 encoder 的编码信息来指导生成。
- tgt_mask 是什么？→ 上三角为 0 的下三角矩阵（look-ahead mask），确保位置 $i$ 只能 attend 到位置 $\leq i$。

## 9. Encoder & Decoder Stack

```python
class Encoder(nn.Module):
    """Encoder: Embedding + Positional Encoding + N 层 EncoderLayer"""
    def __init__(self, vocab_size: int, d_model: int, n_heads: int,
                 n_layers: int, d_ff: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.token_embed = TokenEmbedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len, dropout)
        self.layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        self.norm = nn.LayerNorm(d_model)

    def forward(self, src, src_mask=None):
        # src: (batch, src_len)
        x = self.token_embed(src)          # (batch, src_len, d_model)
        x = self.pos_encoding(x)           # (batch, src_len, d_model)
        for layer in self.layers:
            x = layer(x, src_mask)
        return self.norm(x)                # (batch, src_len, d_model)


class Decoder(nn.Module):
    """Decoder: Embedding + Positional Encoding + N 层 DecoderLayer"""
    def __init__(self, vocab_size: int, d_model: int, n_heads: int,
                 n_layers: int, d_ff: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.token_embed = TokenEmbedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len, dropout)
        self.layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        self.norm = nn.LayerNorm(d_model)

    def forward(self, tgt, encoder_output, src_mask=None, tgt_mask=None):
        # tgt: (batch, tgt_len)
        x = self.token_embed(tgt)          # (batch, tgt_len, d_model)
        x = self.pos_encoding(x)           # (batch, tgt_len, d_model)
        for layer in self.layers:
            x = layer(x, encoder_output, src_mask, tgt_mask)
        return self.norm(x)                # (batch, tgt_len, d_model)
```

## 10. 完整 Transformer 模型

```python
class Transformer(nn.Module):
    """完整的 Transformer 模型"""
    def __init__(self, src_vocab_size: int, tgt_vocab_size: int,
                 d_model: int = 512, n_heads: int = 8,
                 n_layers: int = 6, d_ff: int = 2048,
                 max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.encoder = Encoder(src_vocab_size, d_model, n_heads, n_layers, d_ff, max_len, dropout)
        self.decoder = Decoder(tgt_vocab_size, d_model, n_heads, n_layers, d_ff, max_len, dropout)
        self.output_proj = nn.Linear(d_model, tgt_vocab_size)  # 输出投影到词表大小

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        # src: (batch, src_len)  源序列
        # tgt: (batch, tgt_len)  目标序列（右移一位的 ground truth）
        encoder_output = self.encoder(src, src_mask)   # (batch, src_len, d_model)
        decoder_output = self.decoder(tgt, encoder_output, src_mask, tgt_mask)
        logits = self.output_proj(decoder_output)       # (batch, tgt_len, tgt_vocab_size)
        return logits


def make_masks(src, tgt, src_pad_idx=0, tgt_pad_idx=0):
    """
    生成 src_mask 和 tgt_mask
    src_mask: (batch, 1, 1, src_len) — padding mask
    tgt_mask: (batch, 1, tgt_len, tgt_len) — padding mask + look-ahead mask
    """
    # src padding mask: 把 pad 位置标为 False
    src_mask = (src != src_pad_idx).unsqueeze(1).unsqueeze(2)  # (batch, 1, 1, src_len)

    # tgt padding mask
    tgt_pad_mask = (tgt != tgt_pad_idx).unsqueeze(1).unsqueeze(3)  # (batch, 1, tgt_len, 1)

    # look-ahead mask: 下三角矩阵
    tgt_len = tgt.size(1)
    tgt_sub_mask = torch.tril(torch.ones(tgt_len, tgt_len)).bool()  # 下三角
    tgt_sub_mask = tgt_sub_mask.unsqueeze(0).unsqueeze(0)  # (1, 1, tgt_len, tgt_len)

    # 合并: padding mask AND look-ahead mask
    tgt_mask = tgt_pad_mask & tgt_sub_mask  # (batch, 1, tgt_len, tgt_len)

    return src_mask, tgt_mask
```

## 11. 训练示例

下面是一个简单的 toy 翻译任务训练示例（英文→德文），用于验证整个流程可以跑通：

```python
import torch.optim as optim

# ========== 超参数 ==========
SRC_VOCAB_SIZE = 10000
TGT_VOCAB_SIZE = 10000
D_MODEL = 512
N_HEADS = 8
N_LAYERS = 6
D_FF = 2048
DROPOUT = 0.1
EPOCHS = 10
PAD_IDX = 0

# ========== 构建模型 ==========
model = Transformer(
    src_vocab_size=SRC_VOCAB_SIZE,
    tgt_vocab_size=TGT_VOCAB_SIZE,
    d_model=D_MODEL,
    n_heads=N_HEADS,
    n_layers=N_LAYERS,
    d_ff=D_FF,
    dropout=DROPOUT
)

# 打印参数量
total_params = sum(p.numel() for p in model.parameters())
print(f"Total parameters: {total_params:,}")
# 约 59.5M (59,510,544) — 论文 base model 约 65M（vocab_size=37000）

# ========== 优化器 (使用 Adam + warmup) ==========
optimizer = optim.Adam(model.parameters(), lr=1e-4, betas=(0.9, 0.98), eps=1e-9)
criterion = nn.CrossEntropyLoss(ignore_index=PAD_IDX)

# ========== 模拟数据 ==========
batch_size = 32
src_len = 20
tgt_len = 15

src = torch.randint(1, SRC_VOCAB_SIZE, (batch_size, src_len))   # 随机源序列
tgt = torch.randint(1, TGT_VOCAB_SIZE, (batch_size, tgt_len))   # 随机目标序列
tgt_input = tgt[:, :-1]       # decoder 输入: 去掉最后一个 (teacher forcing)
tgt_output = tgt[:, 1:]       # decoder 目标: 去掉第一个

# ========== 训练循环 ==========
model.train()
for epoch in range(EPOCHS):
    # 生成 mask
    src_mask, tgt_mask = make_masks(src, tgt_input, PAD_IDX, PAD_IDX)

    # 前向传播
    logits = model(src, tgt_input, src_mask, tgt_mask)
    # logits: (batch, tgt_len-1, tgt_vocab_size)

    # 计算 loss
    loss = criterion(
        logits.contiguous().view(-1, TGT_VOCAB_SIZE),
        tgt_output.contiguous().view(-1)
    )

    # 反向传播
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()

    if (epoch + 1) % 2 == 0:
        print(f"Epoch [{epoch+1}/{EPOCHS}], Loss: {loss.item():.4f}")
```

# 面试题

## 基础概念（难度 ★）

### 1. Transformer 的整体架构是怎样的？Encoder 和 Decoder 各包含哪些子层？

**答**：Transformer 由 Encoder 和 Decoder 组成。Encoder 由 N 个相同层堆叠，每层包含 Multi-Head Self-Attention 和 FFN 两个子层，每个子层后接残差连接 + LayerNorm。Decoder 同样 N 层堆叠，每层多一个 Masked Multi-Head Self-Attention（加 look-ahead mask 防止看到未来 token）和一个 Cross-Attention（Q 来自 decoder，K/V 来自 encoder 输出）。

### 2. 为什么 Attention 要除以 $\sqrt{d_k}$？

**答**：假设 $Q$ 和 $K$ 的元素独立且服从标准正态分布，则点积 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的均值为 0、方差为 $d_k$。当 $d_k$ 较大时，点积的绝对值会很大，使 softmax 的输入值分布极端，导致 softmax 输出接近 one-hot，梯度接近 0（饱和区）。除以 $\sqrt{d_k}$ 将方差归一为 1，缓解这个问题。

### 3. 为什么用 LayerNorm 而不是 BatchNorm？

**答**：NLP 任务中序列长度不固定，BatchNorm 在 batch 维度做归一化会跨越不同长度的位置，统计量不稳定。LayerNorm 在每个样本内部（沿 feature 维度）做归一化，不受 batch 大小和序列长度影响，更适合变长序列场景。

### 4. 位置编码为什么用 sin/cos 而不是直接学习？

**答**：(1) sin/cos 编码不需要训练参数，节省计算；(2) 对于任意固定偏移量 $k$，$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性函数，便于模型学习相对位置关系；(3) 可以泛化到比训练时更长的序列（虽然效果会下降）。

## 中等难度（难度 ★★）

### 5. Multi-Head Attention 的参数量和计算量分别是多少？

**答**：参数量 = $4 \times d_{model}^2$（$W^Q, W^K, W^V, W^O$ 各 $d_{model} \times d_{model}$，忽略 bias）。计算量主要来自四次矩阵乘法，Self-Attention 中 $Q=K=V$ 来自同一输入，$QK^T$ 的计算量为 $O(n^2 d_k \cdot h) = O(n^2 d_{model})$，与 $V$ 相乘同理，总计算量 $O(n^2 d_{model})$。

### 6. Decoder 中 tgt_mask 是怎么构造的？为什么需要它？

**答**：tgt_mask 由两部分组成：(1) **padding mask**：将目标序列中 pad token 的位置标记为不可见；(2) **look-ahead mask**（因果 mask）：一个下三角矩阵，确保位置 $i$ 只能 attend 到位置 $\leq i$ 的 token。这是因为 decoder 是自回归生成的，训练时虽然用 teacher forcing 并行输入了整个目标序列，但必须防止模型"偷看"到未来的 token，否则训练时 loss 会虚低但推理时效果很差。

### 7. FFN 为什么用两层而不是一层？有什么作用？

**答**：(1) 两层 FFN 中间有 ReLU 非线性激活，引入了非线性变换能力。如果只用一层线性变换，整个 Attention + FFN 等价于一个线性变换，表达能力大大受限。(2) FFN 的内部维度通常是 $4 \times d_{model}$，起到了"升维→变换→降维"的作用，类似于在更高维空间中做特征交叉。(3) 有研究表明 FFN 是 Transformer 的"知识存储"模块，Attention 负责信息路由，FFN 负责存储和计算。

### 8. Self-Attention 相比 RNN 和 CNN 有什么优势？

**答**：(1) **并行性**：Self-Attention 对所有位置同时计算，不像 RNN 必须逐步递推；(2) **长距离依赖**：任意两个位置之间的路径长度为 $O(1)$，而 RNN 为 $O(n)$，CNN 需要多层堆叠；(3) **可解释性**：Attention 权重可以可视化，直观看到模型在关注哪些位置。缺点是对长序列计算量为 $O(n^2)$，内存消耗大。

## 进阶深入（难度 ★★★）

### 9. Transformer 中残差连接的作用是什么？去掉会怎样？

**答**：残差连接 $x + \text{SubLayer}(x)$ 的作用：(1) 缓解深层网络的梯度消失问题，梯度可以通过残差路径直接回传；(2) 允许子层学习"增量"变化而非完整映射，降低学习难度。如果去掉残差连接，6 层 Transformer 还能训练，但 12 层以上会明显难以收敛，性能大幅下降。

### 10. Transformer 的 Encoder 和 Decoder 中，Cross-Attention 的 Q、K、V 分别来自哪里？有什么直觉理解？

**答**：Cross-Attention 中，Q 来自 decoder 的当前隐藏状态，K 和 V 来自 encoder 的最终输出。直觉理解：decoder 在生成第 $t$ 个 token 时，通过 Q 提出"我现在需要什么信息"的查询，然后在 encoder 输出的所有源序列位置中（K 作为索引），找到最相关的信息并加权求和（V 作为实际内容）。这与翻译时"看源句→生成目标词"的过程高度一致。

### 11. 为什么 Self-Attention 的 Attention Matrix 是对称的（当 Q=K=V 时不做缩放且无 mask）？这有什么问题？

**答**：当 $Q = K$（同一个输入经过同一个线性变换），则 $\text{scores}_{ij} = q_i \cdot k_j = x_i W^T W x_j$，由于 $W^T W$ 是对称矩阵，所以 $\text{scores}_{ij} = \text{scores}_{ji}$，Attention Matrix 对称。这意味着"词 A 对词 B 的关注度 = 词 B 对词 A 的关注度"，缺乏方向性，泛化能力差。实际上因为有多个头、不同的 $W^Q$ 和 $W^K$，以及非线性变换，最终 Attention 并不是严格对称的。

### 12. Transformer 的位置编码有哪些改进方案？各自的优缺点？

**答**：
- **可学习位置编码**（如 BERT）：直接学习一个 Embedding 表，简单但受限于最大长度。
- **相对位置编码**（如 Transformer-XL、T5）：编码相对距离 $i-j$ 而非绝对位置，更好地处理长度外推。
- **旋转位置编码 RoPE**（如 LLaMA）：将位置信息编码为旋转矩阵，作用在 Q 和 K 上，使得点积自然包含相对位置信息，是目前大模型的主流选择。
- **ALiBi**（Press et al.）：不用编码，直接在 Attention Score 上减去与距离成正比的惩罚值，简单高效。

### 13. 如何实现 Transformer 的推理（自回归生成）？有什么加速方法？

**答**：推理时 decoder 逐个生成 token，每生成一个新 token 都要重新跑一遍整个 decoder，效率很低。加速方法：
- **KV Cache**：缓存已计算过的 K、V，新生成一个 token 时只需计算该 token 的 Q 与缓存的 K、V 做 Attention，避免重复计算。
- **Beam Search**：维护 $k$ 个候选序列，提高生成质量。
- **投机采样（Speculative Decoding）**：用小模型快速生成多个 token，再用大模型一次性验证，接受的 token 可以并行保留。
- **Flash Attention**：通过分块计算和 IO 感知优化，减少 Attention 的显存占用和计算延迟。

### 14. Pre-Norm 和 Post-Norm 有什么区别？LayerNorm 和 RMSNorm 有什么区别？为什么现在大模型多用 Pre-Norm + RMSNorm？

**答**：

#### Pre-Norm vs Post-Norm

- **Post-Norm**（原始 Transformer）：$x = \text{Norm}(x + \text{SubLayer}(x))$，先做子层再归一化。
- **Pre-Norm**：$x = x + \text{SubLayer}(\text{Norm}(x))$，先归一化再做子层。

Pre-Norm 的优势：(1) 残差路径上没有被 Norm 打断，梯度流动更顺畅，训练更稳定；(2) 可以使用更大的学习率而不发散。缺点是最终表示质量可能略逊于 Post-Norm（因为最后一个 token 没有经过 Norm），所以推理前通常需要额外做一次 Norm。

#### LayerNorm vs RMSNorm

**LayerNorm** 对输入做两步：(1) 减去均值（中心化）；(2) 除以标准差（缩放）：

$$\text{LayerNorm}(x) = \frac{x - \mu}{\sigma + \epsilon} \cdot \gamma + \beta$$

**RMSNorm** 只做缩放，不做中心化：

$$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x) + \epsilon} \cdot \gamma, \quad \text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2}$$

| 对比维度 | LayerNorm | RMSNorm |
|---------|-----------|----------|
| 中心化（减均值） | ✅ 有 | ❌ 无 |
| 可学习参数 | $\gamma$（缩放）+ $\beta$（偏移） | 仅 $\gamma$（缩放） |
| 计算开销 | 较高（需计算均值和方差） | 较低（只需计算均方根） |
| 效果 | 好 | 相当或略优（论文实验验证） |
| 推理速度 | 基准 | 快约 20%（归一化部分） |

RMSNorm 去掉中心化后效果不降反升的可能原因：(1) 减均值操作会破坏残差路径中携带的"幅度信息"；(2) 更少的参数和计算反而减少了过拟合风险。

#### 当前主流大模型的选择

**Pre-Norm + RMSNorm** 是目前几乎所有主流大模型的标准配置：

| 模型 | Norm 类型 | Norm 位置 |
|------|----------|----------|
| LLaMA 1/2/3 | RMSNorm | Pre-Norm |
| Mistral / Mixtral | RMSNorm | Pre-Norm |
| Qwen 1.5/2 | RMSNorm | Pre-Norm |
| GPT-NeoX / Pythia | LayerNorm | Pre-Norm |
| 原始 Transformer (2017) | LayerNorm | Post-Norm |
| BERT | LayerNorm | Post-Norm |
