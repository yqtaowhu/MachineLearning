# 机器学习知识文档编写

## 流程
1. 明确主题；按仓库约定确定位置与文件名（见「文件命名」）；若已有同类文档先阅读保持一致
2. 按下方模板规划章节
3. 编写内容，遵循「写作规范」
4. 校验：公式格式、目录锚点、例子与面试题数量达标，通读确认递进清晰

## 文档结构模板
```
[1. 概述]                一句话定义 + 为什么重要
[2. 核心原理/公式]        直觉先行，公式后置，推导不跳步
[3. 重要性质]            每条 = 公式 + 直觉解释
[4. 与其他概念的关系]      横向对比与关联
[5. 具体例子]            给出具体例子
[6. 常见面试问题]        8-10 道问答
[参考资料]
```
章节可按主题调整，但**必须保留**：概述、具体例子、常见面试问题。

## 写作规范
- **易懂**：先大白话解释，再严谨定义；公式中每个符号首次出现时解释含义
- **公式**：行内 `$...$`，块级 `$$...$$`；**禁止** `\( \)` / `\[ \]`（多数预览器不识别）；关键结论用 `\boxed{}`
- **例子**：≥2 个，优先生活化场景；四段式「问题 → 步骤 → 计算 → 结果解读」，必须给出具体数字（如"后验 Beta(8,4)，期望 ≈ 0.667"）
- **面试题**：8-10 道难度递增，覆盖概念理解/公式推导/应用场景/进阶延伸，每题附完整答案（直接答案 + 关键公式 + 直觉）

## 文件命名
- 目录：`Math/` `machine-learning/` `NLP/` `Rec/` `Search/` `interview/`
- 命名：数字序号 + 主题，如 `1.beta分布.md`；空目录从 1 开始编号
