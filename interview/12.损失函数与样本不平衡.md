# 损失函数与样本不平衡：CE Loss、Focal Loss 与 Label Smoothing

## 1. 概述

在分类任务中，**交叉熵损失（Cross Entropy Loss）** 是最基础的损失函数。但面对**样本不平衡**（如 99:1 的正负样本比），标准 CE Loss 会被多数类主导，少数类几乎"学不到"。

**Focal Loss** 和 **Label Smoothing** 是两种从不同角度缓解这一问题的方案：

- **Focal Loss**：直接改造损失函数，降低"简单多数类样本"的权重，让模型聚焦"难样本"
- **Label Smoothing**：软化硬标签，防止模型对多数类过度自信，间接改善不平衡

> 一句话总结：**CE Loss 是基础，Focal Loss 从"样本权重"角度解决不平衡，Label Smoothing 从"标签置信度"角度解决不平衡。**

## 2. 交叉熵损失（Cross Entropy Loss）

### 2.1 从信息论到损失函数

**信息熵**衡量"不确定性"：

$$H(p) = -\sum_{i=1}^{C} p_i \log p_i$$

**交叉熵**衡量"用分布 $q$ 编码真实分布 $p$ 时的平均编码长度"：

$$H(p, q) = -\sum_{i=1}^{C} p_i \log q_i$$

其中 $p$ 是真实分布（one-hot 标签），$q$ 是模型预测的概率分布。

**KL 散度**衡量两个分布的差异：

$$D_{KL}(p \| q) = H(p, q) - H(p) = \sum_{i=1}^{C} p_i \log \frac{p_i}{q_i}$$

由于真实标签 $p$ 固定，$H(p)$ 是常数，所以**最小化交叉熵 $H(p,q)$ 等价于最小化 KL 散度**——这就是为什么用交叉熵作为分类损失函数。

### 2.2 公式推导

**多分类 CE Loss**：设 $C$ 个类别，真实标签为 one-hot 向量 $y$（$y_i \in \{0, 1\}$，$\sum y_i = 1$），模型输出概率 $\hat{y} = \text{softmax}(z)$，其中 $z$ 是 logits：

$$\mathcal{L}_{CE} = -\sum_{i=1}^{C} y_i \log \hat{y}_i$$

由于 $y$ 是 one-hot，只有真实类别 $c$ 对应项为 1，其余为 0，所以简化为：

$$\boxed{\mathcal{L}_{CE} = -\log \hat{y}_c}$$

其中 $\hat{y}_c$ 是模型对真实类别 $c$ 的预测概率。

**二分类 CE Loss**（BCE Loss）：$C=2$，$y \in \{0, 1\}$：

$$\mathcal{L}_{BCE} = -[y \log \hat{y} + (1-y) \log(1-\hat{y})]$$

### 2.3 梯度分析

对 logits $z_c$（真实类别对应的 logit）求梯度：

$$\frac{\partial \mathcal{L}_{CE}}{\partial z_c} = \hat{y}_c - 1$$

对其他类别 $i \neq c$：

$$\frac{\partial \mathcal{L}_{CE}}{\partial z_i} = \hat{y}_i$$

**关键发现**：梯度大小只取决于预测概率 $\hat{y}$。当模型对正确类别很自信时（$\hat{y}_c \to 1$），梯度 $\hat{y}_c - 1 \to 0$——**即使样本分类正确，仍会产生梯度更新**，只是方向是"让正确概率更高"。

### 2.4 为什么 CE Loss 在样本不平衡时表现差

假设正负样本比为 1:99：

- **多数类（负样本）**：占 99%，每个样本产生梯度，累积梯度主导参数更新方向
- **少数类（正样本）**：占 1%，梯度被淹没

更具体地：假设模型已经能正确分类 90% 的负样本（$\hat{y}_{\text{neg}} \approx 0.9$），但对正样本预测很差（$\hat{y}_{\text{pos}} \approx 0.3$）。

每个负样本的梯度：$|0.9 - 1| = 0.1$（小，但有 99 倍的数量优势）

每个正样本的梯度：$|0.3 - 1| = 0.7$（大，但数量太少）

总梯度贡献：负样本 $99 \times 0.1 = 9.9$，正样本 $1 \times 0.7 = 0.7$

**负样本的总梯度仍是正样本的 14 倍**，模型继续偏向负样本。

## 3. Focal Loss：聚焦难样本

> **论文**：Lin et al., 2017. *Focal Loss for Dense Object Detection*（Facebook AI，解决目标检测中的正负样本极度不平衡）

### 3.1 动机

目标检测中，正负样本比可达 **1:10000**。标准 CE Loss 的问题：

1. 大量负样本（背景）的梯度累积主导训练
2. 其中大部分是"简单负样本"（模型已经很自信是背景），贡献的梯度虽小但数量巨大
3. 模型被这些"简单但量大"的样本带偏，学不好少数类

**核心思想**：给每个样本乘一个**调制因子**——预测越准（$p_t$ 越大），调制因子越小，该样本的 loss 权重越低。

### 3.2 公式

$$\boxed{\mathcal{L}_{FL} = -\alpha_t (1 - p_t)^\gamma \log p_t}$$

其中：
- $p_t$ 是模型对**真实类别**的预测概率（二分类中，正样本 $p_t = \hat{y}$，负样本 $p_t = 1 - \hat{y}$）
- $\gamma \geq 0$ 是**聚焦参数**（focusing parameter），控制调制强度
- $\alpha_t$ 是**平衡因子**，用于调节正负样本的权重比

**与 CE Loss 的关系**：
- 当 $\gamma = 0$ 时，Focal Loss 退化为带 $\alpha$ 的 CE Loss
- 当 $\gamma = 0$ 且 $\alpha = 1$ 时，退化为标准 CE Loss

### 3.3 调制因子 $(1-p_t)^\gamma$ 的作用

| 样本类型 | $p_t$ | $(1-p_t)^\gamma$（$\gamma=2$） | 效果 |
|---------|-------|-------------------------------|------|
| 简单正样本 | 0.9 | $(0.1)^2 = 0.01$ | loss 降为原来的 1% |
| 中等样本 | 0.5 | $(0.5)^2 = 0.25$ | loss 降为原来的 25% |
| 难样本 | 0.1 | $(0.9)^2 = 0.81$ | loss 几乎不变 |

**直觉**：调制因子像一个"自动注意力机制"——模型已经学好的样本被自动降权，模型还没学好的样本保持高权重。

**$\gamma$ 的影响**：
- $\gamma = 0$：无调制，退化为 CE Loss
- $\gamma = 0.5$：温和降权
- $\gamma = 2$：论文推荐值，强降权
- $\gamma = 5$：极端降权，几乎所有样本都被忽略

### 3.4 平衡因子 $\alpha_t$

即使加了调制因子，正负样本的总量仍可能不平衡。$\alpha_t$ 显式控制正负样本的权重比：

$$\alpha_t = \begin{cases} \alpha, & \text{正样本} \\ 1 - \alpha, & \text{负样本} \end{cases}$$

论文推荐 $\alpha = 0.25$（正样本权重 0.25，负样本权重 0.75），配合 $\gamma = 2$ 使用。

$\alpha$ 的设定方式：
- **固定值**：根据正负样本比例设定，如正样本占 1%，则 $\alpha = 0.99$
- **可学习参数**：将 $\alpha$ 作为网络参数一起训练
- **逆频率**：$\alpha_c = \frac{N}{C \cdot n_c}$，其中 $N$ 是总样本数，$C$ 是类别数，$n_c$ 是类别 $c$ 的样本数

### 3.5 重要性质

1. **自动降权简单样本**：不需要显式采样，调制因子自动完成
2. **聚焦难样本**：难样本的 loss 权重几乎不变，梯度信号不被稀释
3. **不改变数据分布**：与过采样/欠采样不同，Focal Loss 只改损失函数，不改变训练数据
4. **对异常值更鲁棒**：噪声样本通常被模型预测为"简单"（因为特征随机），反而会被降权

## 4. Label Smoothing：软化标签

> **论文**：Szegedy et al., 2016. *Rethinking the Inception Architecture for Computer Vision*（Google，ImageNet 竞赛经验）

### 4.1 动机

标准 CE Loss 使用 **hard label**（one-hot 标签），导致两个问题：

1. **过度自信**：模型被训练为对正确类别输出概率接近 1.0，logits 趋向无穷大
2. **泛化性差**：过度自信导致决策边界过于尖锐，对测试集不利
3. **样本不平衡加剧**：对多数类过度自信后，模型对少数类的预测空间被压缩

### 4.2 公式

将 hard label 替换为 **soft label**：

$$y_i^{\text{soft}} = (1 - \epsilon) \cdot y_i^{\text{hard}} + \frac{\epsilon}{C}$$

其中：
- $\epsilon \in [0, 1]$ 是**平滑系数**（smoothing parameter），通常取 0.1
- $C$ 是类别数
- $y_i^{\text{hard}}$ 是原始 one-hot 标签

**具体效果**：
- 真实类别的标签从 $1.0$ 降为 $1 - \epsilon + \frac{\epsilon}{C} = 1 - \epsilon \cdot \frac{C-1}{C}$
- 非真实类别的标签从 $0.0$ 升为 $\frac{\epsilon}{C}$

以 $C = 4$、$\epsilon = 0.1$ 为例：
- 真实类别标签：$1 - 0.1 \times \frac{3}{4} = 0.925$
- 非真实类别标签：$\frac{0.1}{4} = 0.025$
- 验证：$0.925 + 3 \times 0.025 = 1.0$ ✓

### 4.3 直觉理解

Label Smoothing 的本质是告诉模型：

> "不要 100% 确定是类别 A，留一点概率给其他类别。"

这像是一个**正则化信号**——防止模型过度拟合训练集的硬标签，鼓励它学习更平滑的决策边界。

**与知识蒸馏的关系**：Label Smoothing 可以看作一种极简的"知识蒸馏"——用 soft label 替代 hard label，让模型学到类别间的"软关系"。

### 4.4 Label Smoothing 与样本不平衡的关系

Label Smoothing **不是专门为样本不平衡设计的**，但它从以下角度间接缓解不平衡：

1. **防止多数类过度自信**：多数类样本的标签从 1.0 降为 0.925，模型不会把全部梯度用于"把多数类概率推到 1.0"，减少了多数类对梯度的垄断
2. **给少数类更多梯度空间**：非真实类别获得 $\frac{\epsilon}{C}$ 的概率，少数类作为"非真实类别"时也能获得微小的梯度信号
3. **正则化效果**：防止模型对多数类过拟合，相当于隐式的正则化

**但要注意**：Label Smoothing 对不平衡的缓解是**间接且有限的**。如果正负样本比为 1:1000，仅靠 Label Smoothing 远远不够，需要配合 Focal Loss 或重采样。

### 4.5 重要性质

1. **防止过度自信**：模型输出的最大概率被限制在 $1 - \epsilon \cdot \frac{C-1}{C}$ 附近
2. **logits 有界**：没有 Label Smoothing 时，正确类别的 logit 会趋向 $+\infty$；有 Label Smoothing 时，logit 趋向 $\log\frac{1-\epsilon+\epsilon/C}{\epsilon/C}$，是一个有限值
3. **提升泛化性**：实验表明 Label Smoothing 通常提升 0.5-1% 的测试集精度
4. **与知识蒸馏冲突**：如果用 Label Smoothing 训练的教师模型去蒸馏学生模型，效果会变差——因为 soft label 中的"暗知识"是均匀分布，不包含真实的类别间关系

## 5. 三者的关系与横向对比

| 特性 | CE Loss | Focal Loss | Label Smoothing |
|------|---------|-----------|----------------|
| 公式 | $-\log p_t$ | $-\alpha_t(1-p_t)^\gamma \log p_t$ | $-\sum y_i^{\text{soft}} \log \hat{y}_i$ |
| 设计目标 | 基础分类损失 | 解决样本不平衡 | 防止过度自信 |
| 对简单样本 | 正常权重 | 自动降权 | 略微降权 |
| 对难样本 | 正常权重 | 保持高权重 | 略微降权 |
| 对不平衡的缓解 | ✗ 无 | ✓ 直接（调制因子+平衡因子） | △ 间接（正则化） |
| 超参数 | 无 | $\gamma$（聚焦）、$\alpha$（平衡） | $\epsilon$（平滑系数） |
| 典型取值 | — | $\gamma=2, \alpha=0.25$ | $\epsilon=0.1$ |
| 计算开销 | 低 | 略高（幂运算） | 低（标签预处理） |
| 典型应用 | 通用分类 | 目标检测、不平衡分类 | 图像分类、Transformer |

**组合使用**：
- **Focal Loss + Label Smoothing**：可以同时获得两者的优势——Focal Loss 聚焦难样本，Label Smoothing 防止过度自信。在目标检测（如 RetinaNet）中常见这种组合
- **CE Loss + Label Smoothing**：最常见的组合，几乎所有现代 Transformer（BERT、ViT）都使用

## 6. 具体例子

### 例子 1：Focal Loss 如何改变样本权重

**问题**：二分类任务，正负样本比 1:99。给定一个简单负样本（$p_t = 0.9$）和一个难正样本（$p_t = 0.1$），分别计算 CE Loss 和 Focal Loss（$\gamma=2, \alpha=0.25$）的值。

**步骤**：

**CE Loss**：
$$\mathcal{L}_{CE}(\text{简单负}) = -\log(0.9) = 0.105$$
$$\mathcal{L}_{CE}(\text{难正}) = -\log(0.1) = 2.303$$

**Focal Loss**（$\gamma=2, \alpha=0.25$）：

简单负样本（$\alpha_t = 1 - 0.25 = 0.75$）：
$$\mathcal{L}_{FL} = -0.75 \times (1-0.9)^2 \times \log(0.9) = -0.75 \times 0.01 \times (-0.105) = 0.000788$$

难正样本（$\alpha_t = 0.25$）：
$$\mathcal{L}_{FL} = -0.25 \times (1-0.1)^2 \times \log(0.1) = -0.25 \times 0.81 \times (-2.303) = 0.466$$

**结果解读**：

| 样本 | CE Loss | Focal Loss | 降权比例 |
|------|---------|-----------|---------|
| 简单负样本 | 0.105 | 0.000788 | 降为 0.75% |
| 难正样本 | 2.303 | 0.466 | 降为 20.2% |

- 简单负样本的 loss 从 0.105 降到 0.000788，**几乎被忽略**
- 难正样本的 loss 从 2.303 降到 0.466，**仍保持显著梯度**
- 在 CE Loss 下，难正样本的梯度是简单负样本的 22 倍，但数量只有 1/99，总贡献仍被淹没
- 在 Focal Loss 下，99 个简单负样本的总 loss $= 99 \times 0.000788 = 0.078$，1 个难正样本的 loss $= 0.466$，**正样本的贡献是负样本的 6 倍**——成功反转了不平衡

### 例子 2：Label Smoothing 如何改变标签分布

**问题**：4 分类任务，真实标签为类别 0。分别计算 $\epsilon = 0$（hard label）和 $\epsilon = 0.1$（soft label）下的 CE Loss，假设模型预测概率为 $[0.7, 0.1, 0.1, 0.1]$。

**步骤**：

**Hard Label**（$\epsilon = 0$）：
$$y^{\text{hard}} = [1, 0, 0, 0]$$
$$\mathcal{L}_{CE} = -1 \times \log(0.7) = 0.357$$

**Soft Label**（$\epsilon = 0.1$）：
$$y^{\text{soft}} = [1 - 0.1 \times \frac{3}{4}, \frac{0.1}{4}, \frac{0.1}{4}, \frac{0.1}{4}] = [0.925, 0.025, 0.025, 0.025]$$
$$\mathcal{L}_{LS} = -(0.925 \times \log(0.7) + 3 \times 0.025 \times \log(0.1))$$
$$= -(0.925 \times (-0.357) + 3 \times 0.025 \times (-2.303))$$
$$= 0.330 + 0.173 = 0.503$$

**结果解读**：
- Hard label 下 loss $= 0.357$，模型只需要把类别 0 的概率推高
- Soft label 下 loss $= 0.503$，**loss 变大了**——因为模型不仅要让类别 0 概率高，还要让其他类别的概率不低于 $\frac{\epsilon}{C} = 0.025$
- 这个额外的"惩罚"阻止模型把类别 0 的概率推到 1.0，**防止过度自信**
- 当模型预测 $[0.925, 0.025, 0.025, 0.025]$ 时，soft label 的 loss 达到最小值 0，而 hard label 的 loss 在 $[1, 0, 0, 0]$ 时才为 0

## 7. 常见面试问题

### Q1：交叉熵损失为什么适合做分类任务的损失函数？

**答**：

三个核心原因：

1. **信息论基础**：最小化交叉熵 $H(p, q)$ 等价于最小化 KL 散度 $D_{KL}(p \| q)$，即让预测分布 $q$ 逼近真实分布 $p$
2. **梯度友好**：对 logits 求梯度后为 $\hat{y}_i - y_i$，形式简洁，预测越错梯度越大
3. **与 softmax 天然配合**：softmax 输出概率分布，交叉熵衡量分布差异，两者组合的梯度不出现除零或梯度消失

### Q2：Focal Loss 的调制因子 $(1-p_t)^\gamma$ 是如何解决样本不平衡的？

**答**：

调制因子通过**自动降权简单样本**来解决不平衡：

- 简单样本（$p_t$ 大）：$(1-p_t)^\gamma \to 0$，loss 权重被大幅降低
- 难样本（$p_t$ 小）：$(1-p_t)^\gamma \to 1$，loss 权重几乎不变

在样本不平衡场景中，多数类通常被模型预测为"简单"（因为数量多、特征明显），所以多数类样本的 loss 权重被自动降低，少数类的难样本保持高权重。

**关键公式**：$\mathcal{L}_{FL} = -\alpha_t (1-p_t)^\gamma \log p_t$

**直觉**：不需要手动做欠采样，Focal Loss 自动完成"让模型关注难样本"的过程。

### Q3：Label Smoothing 的数学本质是什么？为什么能提升泛化性？

**答**：

**数学本质**：将 one-hot 标签替换为均匀分布与 one-hot 的凸组合：

$$y^{\text{soft}} = (1-\epsilon) \cdot y^{\text{hard}} + \epsilon \cdot u$$

其中 $u = [1/C, 1/C, \ldots, 1/C]$ 是均匀分布。

**为什么能提升泛化性**：

1. **防止过度自信**：模型不再被训练为输出概率接近 1.0，logits 保持有界
2. **正则化效果**：等价于在 logits 上添加了一个 $L_2$ 正则项（有论文证明），抑制模型对训练集的过拟合
3. **平滑决策边界**：模型学到更平滑的类别边界，对测试集的扰动更鲁棒

### Q4：Focal Loss 和 Label Smoothing 都能缓解样本不平衡，它们的区别是什么？

**答**：

| 维度 | Focal Loss | Label Smoothing |
|------|-----------|----------------|
| 解决思路 | 直接降低简单样本的 loss 权重 | 软化标签，防止多数类过度自信 |
| 对不平衡的缓解 | 直接、显著 | 间接、有限 |
| 核心机制 | 调制因子 $(1-p_t)^\gamma$ | 标签平滑 $\epsilon/C$ |
| 适用场景 | 极度不平衡（1:1000+） | 轻中度不平衡或防止过拟合 |
| 是否改变标签 | 否 | 是 |

**一句话**：Focal Loss 是"对症下药"（专门解决不平衡），Label Smoothing 是"旁敲侧击"（主要防止过拟合，间接缓解不平衡）。

### Q5：Focal Loss 中 $\gamma$ 过大会有什么问题？

**答**：

$\gamma$ 过大的问题：

1. **梯度消失**：当 $\gamma$ 很大（如 $\gamma = 5$），几乎所有样本的 $(1-p_t)^\gamma \to 0$，loss 趋近于 0，梯度消失，模型几乎不学习
2. **对噪声敏感**：少数真正的难样本中可能包含噪声标签，$\gamma$ 过大导致模型过度拟合这些噪声
3. **训练不稳定**：训练初期模型预测都很差（$p_t$ 小），$(1-p_t)^\gamma$ 接近 1，所有样本权重都很高；训练后期突然降权，导致梯度分布剧变

**实践建议**：$\gamma = 2$ 是最常用的值， rarely 超过 5。

### Q6：Label Smoothing 为什么会影响知识蒸馏的效果？

**答**：

知识蒸馏中，学生模型需要学习教师模型的 **soft predictions**（类别间的相对关系，即"暗知识"）。

Label Smoothing 给非真实类别分配的是**均匀概率** $\frac{\epsilon}{C}$，这不代表真实的类别间关系。例如，猫和狗的图片，Label Smoothing 给"汽车"类别的概率与给"狗"类别的概率相同——这显然是不合理的。

**结果**：用 Label Smoothing 训练的教师模型，其 soft predictions 中的"暗知识"被均匀分布污染，学生模型学不到有意义的类别关系，蒸馏效果变差。

**解决方案**：训练教师模型时不用 Label Smoothing，或者用知识蒸馏自己的 soft labels 替代 Label Smoothing。

### Q7：在二分类任务中，Focal Loss 的梯度是什么样的？

**答**：

设二分类中真实标签 $y = 1$，预测概率 $p = \sigma(z)$，则 $p_t = p$：

$$\mathcal{L}_{FL} = -(1-p)^\gamma \log p$$

对 logit $z$ 求梯度（利用 $\frac{dp}{dz} = p(1-p)$）：

$$\frac{\partial \mathcal{L}_{FL}}{\partial z} = -(1-p)^\gamma \cdot \frac{1}{p} \cdot p(1-p) + \gamma(1-p)^{\gamma-1} \log p \cdot p(1-p)$$

化简后：

$$\frac{\partial \mathcal{L}_{FL}}{\partial z} = -(1-p)^{\gamma+1} + \gamma(1-p)^\gamma \cdot p \cdot \log p \cdot (1-p)$$

**关键观察**：
- 当 $p \to 1$（简单样本）：$(1-p)^{\gamma+1} \to 0$，梯度趋近于 0
- 当 $p \to 0$（难样本）：$(1-p)^{\gamma+1} \to 1$，梯度保持较大

对比 CE Loss 的梯度 $\frac{\partial \mathcal{L}_{CE}}{\partial z} = p - 1$，Focal Loss 的梯度多了一个 $(1-p)^\gamma$ 的衰减因子。

### Q8：Label Smoothing 的 $\epsilon$ 设太大会有什么问题？

**答**：

$\epsilon$ 过大的问题：

1. **标签信息被稀释**：当 $\epsilon \to 1$，soft label 趋近于均匀分布 $[1/C, \ldots, 1/C]$，真实标签的信息几乎丢失，模型无法区分不同类别
2. **模型学不到有用特征**：所有类别的目标分布几乎相同，模型倾向于输出均匀分布，准确率下降
3. **训练困难**：模型需要更长时间才能收敛，因为目标分布太"模糊"

**实践建议**：$\epsilon = 0.1$ 是最常用的值，rarely 超过 0.2。对于类别数 $C$ 很大的任务（如 1000 类），$\epsilon$ 可以适当小一些（如 0.05），因为 $\frac{\epsilon}{C}$ 已经很小。

### Q9：如何处理极度不平衡的分类任务（如 1:10000）？

**答**：

综合方案（按优先级）：

1. **数据层面**：
   - 过采样少数类（SMOTE 等）
   - 欠采样多数类（随机或基于聚类）
   - 数据增强少数类

2. **损失函数层面**：
   - **Focal Loss**：$\gamma = 2, \alpha = 0.99$（少数类权重高）
   - **加权 CE Loss**：$\mathcal{L} = -w_c \log \hat{y}_c$，$w_c = \frac{N}{C \cdot n_c}$

3. **评估指标层面**：
   - 不用 Accuracy，改用 F1-score、AUC-PR、MCC
   - 关注少数类的召回率

4. **模型层面**：
   - 两阶段训练：先用 CE Loss 预训练，再用 Focal Loss 微调
   - 集成学习：对少数类做 bagging

**最佳实践**：Focal Loss + 加权采样 + F1-score 评估，三者结合效果最好。

### Q10：Focal Loss 和加权 CE Loss 有什么区别？

**答**：

两者都能调节样本权重，但机制不同：

| 维度 | 加权 CE Loss | Focal Loss |
|------|-------------|-----------|
| 权重来源 | 手动设定（基于类别频率） | 自动计算（基于预测概率） |
| 对同类样本 | 所有同类样本权重相同 | 简单样本权重低，难样本权重高 |
| 自适应 | ✗ 固定 | ✓ 动态调整 |
| 超参数 | 类别权重 $w_c$ | $\gamma$（聚焦）、$\alpha$（平衡） |

**关键区别**：加权 CE Loss 对同一个类别的所有样本一视同仁，而 Focal Loss 能区分同类样本中的"简单"和"难"。例如，99 个负样本中，有些 $p_t = 0.99$（极简单），有些 $p_t = 0.5$（较难），Focal Loss 会给后者更高的权重，而加权 CE Loss 给两者相同权重。
