# Normalization 总结：从 BN 到 LN/GN/RMSNorm

## 1. 概述

Normalization（归一化）的核心任务是把网络中某一层的输入**拉回到稳定的分布**（零均值、单位方差附近），再用可学习的缩放和平移参数 $\gamma$、$\beta$ 恢复表达能力。

**为什么重要**：深层网络训练时，前面层的参数一更新，后面层的输入分布就跟着变（Internal Covariate Shift），导致后面层要"不停追着分布跑"，收敛慢、易饱和。Normalization 相当于给每一层都"铺平了路"。

**一句话理解各变种**：

> 它们公式几乎一样，唯一区别是——**沿哪个维度计算均值和方差**。

- 沿 **batch 维度**算 → Batch Normalization（BN）
- 沿 **特征/隐藏维度**算 → Layer Normalization（LN）
- 沿 **单张图的内部**算 → Instance Normalization（IN）
- 分组沿特征维度算 → Group Normalization（GN）
- 只除均方根、不减均值 → RMSNorm

## 2. 统一视角：所有 Normalization 在"对谁归一化"

所有归一化算法都可以写成同一个公式：

$$y = \gamma \cdot \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta$$

其中：

- $x$：当前层的输入，某一维度上的取值
- $\mu_B$：归一化统计量的**均值**
- $\sigma_B^2$：归一化统计量的**方差**
- $\gamma$（缩放）、$\beta$（平移）：**可学习参数**，让网络有能力"撤销"归一化
- $\epsilon$：数值稳定项，防止除零（通常取 $10^{-5}$）

考虑一个形状为 $[N, C, H \times W]$ 的图像特征（$N$ 个样本、$C$ 个通道、每个通道 $H \times W$ 个空间位置），不同归一化方法的统计量计算范围：

| 方法 | 均值/方差在哪些元素上计算 | 直觉 |
|------|--------------------------|------|
| BN | 同一通道的**所有样本 + 所有空间位置** | "对每个通道跨 batch 归一化" |
| LN | 同一样本的**所有通道 + 所有空间位置** | "对每个样本整体归一化" |
| IN | 同一样本的**同一通道的所有空间位置** | "对每张图的每个通道归一化" |
| GN | 同一样本内**分组后的每组通道 + 空间位置** | BN 和 IN 的折中 |

用一张 2×3（N×C）的格子图理解（每个格子里还有若干空间位置，图中省略）：

```
         C1        C2        C3
N1   [ N1,C1 ] [ N1,C2 ] [ N1,C3 ]
N2   [ N2,C1 ] [ N2,C2 ] [ N2,C3 ]

BN : 纵向合并 (N1,C1)+(N2,C1) → 一起算均值方差
LN : 横向合并 (N1,C1)+(N1,C2)+(N1,C3) → 一起算均值方差
IN : 单个格子 (N1,C1) 内部 → 自己算均值方差
```

**核心区别一句话**：BN 是"竖着算"（跨样本、同特征），LN 是"横着算"（同样本、跨特征）。

## 3. Batch Normalization（BN）

> **论文**：Ioffe & Szegedy, 2015. *Batch Normalization: Accelerating Deep Network Training*

### 3.1 动机：Internal Covariate Shift

网络中参数变化引起**内部结点数据分布**发生变化的过程称为 Internal Covariate Shift（ICS）。

考虑两层结构：

$$z = w \cdot x, \quad a = g(z)$$

其中 $g$ 是 sigmoid/tanh 激活函数。随着训练推进 $w$ 不断增大，$z$ 的绝对值变大，激活值很容易落入**饱和区**——梯度接近 0，训练停滞。

两种解决思路：

1. **换激活函数**：使用 ReLU 等非饱和激活函数缓解梯度饱和
2. **稳住分布**：让激活函数的输入分布保持稳定，避免落入饱和区——这正是 Normalization 的思路

### 3.2 公式与训练/推理行为差异

**训练时**：统计量来自当前 mini-batch：

$$\mu_B = \frac{1}{m}\sum_{i=1}^{m} x_i, \quad \sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m}(x_i - \mu_B)^2$$

其中 $m$ 是 batch 内样本数。同时用滑动平均维护全局统计量：

$$\mu_{\text{global}} \leftarrow \lambda \cdot \mu_{\text{global}} + (1-\lambda) \cdot \mu_B$$

其中 $\lambda$ 是动量系数（通常取 0.9 或 0.999）。

**推理时**：使用**训练期间累积的全局均值和方差**（固定不变），而不是当前 batch 的统计量。

为什么这么做：

1. **一致性需求**：推理时可能只有单样本或小批量，逐 batch 计算统计量极不稳定
2. **确定性需求**：固定统计量保证同一输入永远得到同一输出，模型行为可复现

\boxed{\text{BN 训练用 batch 统计量（有随机性），推理用全局滑动统计量（确定性）}}

**PyTorch 实现**：

```python
import torch
import torch.nn as nn

x = torch.randn(4, 3, 8, 8)  # (batch=4, channel=3, H=8, W=8) 图像特征

bn = nn.BatchNorm2d(num_features=3)  # 每个通道一组可学习 gamma/beta，共 3 组
out = bn(x)                          # (4, 3, 8, 8)

# 训练/推理行为差异：需要手动切换模式
bn.train()   # 用当前 batch 统计量（有随机性），同时更新滑动平均
bn.eval()    # 用累积的全局统计量（确定性），输出不再随 batch 组成变化

# 手写实现，验证统计量范围：对每个通道在 (N, H, W) 维上计算
mu = x.mean(dim=(0, 2, 3), keepdim=True)                  # (1, 3, 1, 1) 每个通道一个均值
var = x.var(dim=(0, 2, 3), keepdim=True, unbiased=False)  # (1, 3, 1, 1) 每个通道一个方差
bn_manual = (x - mu) / torch.sqrt(var + bn.eps)           # (4, 3, 8, 8)，与 bn.train() 的输出一致
```

### 3.3 优势

1. **加速收敛**：每层输入的均值方差都被稳定在固定范围，层与层之间"解耦"，后层不必不停适应前层分布的变化，可以用更大的学习率
2. **简化调参**：对权重初始化和尺度不那么敏感，训练更稳定
3. **允许饱和激活函数**：把输入拉回非饱和区，sigmoid/tanh 网络也能训得动，缓解梯度消失
4. **隐式正则化**：mini-batch 统计量是对全体数据的估计，不同 batch 之间有随机噪声，类似 Dropout 给训练"加扰动"，抑制过拟合

### 3.4 局限

1. **依赖 batch size**：batch 太小（如目标检测、大模型训练中常见 batch=1~8）时，统计量噪声极大，BN 反而有害
2. **训练/推理不一致**：两套统计量带来隐式 bug 温床（如微调时忘记切换 eval 模式）
3. **不适合变长序列**：NLP 中 batch 内各句长度不一，同一位置上"不同样本的同一特征"缺乏可共享的统计意义
4. **破坏幅度信息**：减均值会削弱残差路径中的信号幅度信息（后面 RMSNorm 的动机）

## 4. Layer Normalization（LN）

> **论文**：Ba et al., 2016. *Layer Normalization*
> **应用**：RNN、Transformer（BERT、GPT）、几乎所有 NLP 模型

LN 对**每个样本自身**在特征维度上计算均值和方差：

$$\mu = \frac{1}{d}\sum_{i=1}^{d} x_i, \quad \sigma^2 = \frac{1}{d}\sum_{i=1}^{d}(x_i - \mu)^2$$

其中 $d$ 是特征维度（如词向量维度）。以 Transformer 的 hidden state 形状 $[\text{batch}, \text{seq\_len}, d]$ 为例，LN 沿最后一维 $d$ 归一化，与 batch、序列长度完全无关。

**为什么 NLP 更适合 LN 而不是 BN**：

- 一个 batch 的文本中，**词序并不决定语义**，任何词都可能出现在任何位置；BN 对"每个位置跨样本"做归一化，隐含假设了"位置 $i$ 的特征在不同样本间同分布"，这不符合语言规律
- 各样本序列长度不一，按位置对齐的统计量没有意义
- LN 是**每个句子内部**归一化，且一般在 $d$ 维（词向量维度）上计算——这一维度上各特征的量纲相同，统计量有意义

**额外优点**：LN 训练和推理行为完全一致（不依赖 batch），天然规避 BN 的训练/推理不一致问题。

**PyTorch 实现**：

```python
h = torch.randn(2, 5, 768)  # (batch=2, seq_len=5, d=768) Transformer hidden state

ln = nn.LayerNorm(normalized_shape=768)  # 沿最后一维 d 归一化，每维一对可学习 gamma/beta
out = ln(h)                              # (2, 5, 768)，统计量与 batch、seq_len 完全无关

# 手写实现，验证统计量范围：对每个 token 在 d 维上计算
mu = h.mean(dim=-1, keepdim=True)                   # (2, 5, 1) 每个 token 一个均值
var = h.var(dim=-1, keepdim=True, unbiased=False)   # (2, 5, 1) 每个 token 一个方差
ln_manual = (h - mu) / torch.sqrt(var + ln.eps)     # (2, 5, 768)，与 ln(h) 一致
```

## 5. Instance Normalization 与 Group Normalization

### Instance Normalization（IN）

对**每个样本的每个通道单独**归一化（在空间维度 $H \times W$ 上算统计量）：

**典型应用**：图像风格迁移（StyleGAN、Pix2Pix）。风格信息恰恰体现在每个通道特征的均值和方差上——"对比度、色调"本质上是通道级统计量。IN 把每个实例每个通道的统计量抹平，相当于"去除实例自身的风格"，把内容与风格解耦。

### Group Normalization（GN）

> **论文**：Wu & He, 2018. *Group Normalization*

把通道分成 $G$ 组（如 32 组），在**同一样本的同一组通道**上算统计量：

- $G = C$（每组 1 个通道）→ 退化为 IN
- $G = 1$（所有通道一组）→ 退化为 LN

**动机**：目标检测、分割任务中 batch 很小（GPU 显存被大分辨率图像占用），BN 统计量不准。GN 不依赖 batch size，在小 batch 场景下稳定优于 BN，是检测/分割任务的标配。

\boxed{\text{GN 是 IN 与 LN 的折中：小 batch 下替代 BN，通道分组提供"组内多样性"保证统计量稳定}}

**PyTorch 实现**：

```python
x = torch.randn(4, 6, 8, 8)  # (N=4, C=6, H=8, W=8)

# IN：每个样本每个通道单独归一化，统计量在 (H, W) 上算
inn = nn.InstanceNorm2d(num_features=6)     # 默认 affine=False，无可学习参数
out_in = inn(x)                             # (4, 6, 8, 8)

# GN：把 6 个通道分成 G=3 组（每组 2 个通道），组内归一化
gn = nn.GroupNorm(num_groups=3, num_channels=6)  # 每组一对可学习 gamma/beta
out_gn = gn(x)                              # (4, 6, 8, 8)

# 验证退化关系：分组数决定 GN 退化为 IN 或 LN
nn.GroupNorm(num_groups=6, num_channels=6)  # G=C → 退化为 IN
nn.GroupNorm(num_groups=1, num_channels=6)  # G=1 → 退化为 LN（不含 beta 时）

# 手写 IN 实现，验证统计量范围：每个 (n, c) 单独在 (H, W) 上算
mu = x.mean(dim=(2, 3), keepdim=True)                   # (4, 6, 1, 1) 每个样本每个通道一个均值
var = x.var(dim=(2, 3), keepdim=True, unbiased=False)   # (4, 6, 1, 1)
in_manual = (x - mu) / torch.sqrt(var + inn.eps)        # (4, 6, 8, 8)，与 inn(x) 一致
```

## 6. 现代演进：Pre-Norm 与 RMSNorm

### 6.1 Post-Norm vs Pre-Norm

Transformer 中 Norm 的摆放位置有两种：

**Post-Norm**（原始 Transformer、BERT）：

$$x = \text{Norm}(x + \text{Sublayer}(x))$$

Norm 在残差连接**之后**。优点是最终效果上限略高；缺点是深网络（几十层以上）梯度传播路径上每层都被 Norm"扰动"，需要 warmup 精细调学习率，否则容易训崩。

**Pre-Norm**（GPT 系列、LLaMA）：

$$x = x + \text{Sublayer}(\text{Norm}(x))$$

Norm 只作用于子层**输入**，残差主干是一条"干净的高速通路"，梯度可以无阻碍地直通底层。优点是训练极其稳定、几乎不需要 warmup 调参；代价是效果上限通常略低于精调的 Post-Norm。

\boxed{\text{现代大模型标配：Pre-Norm + RMSNorm，牺牲一点理论上限，换取深层网络的训练稳定性}}

### 6.2 RMSNorm：去均值化的 LayerNorm

> **论文**：Zhang & Sennrich, 2019. *Root Mean Square Layer Normalization*
> **应用**：LLaMA 1/2/3、Mistral、Qwen 等

$$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \cdot \gamma, \quad \text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2 + \epsilon}$$

其中 $\text{RMS}(x)$ 是均方根。与 LayerNorm 相比：

| 特性 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 中心化（减均值） | ✓ | ✗ |
| 除标准差 | ✓ | ✓（除均方根） |
| 可学习参数 | $\gamma$、$\beta$ 两个 | 仅 $\gamma$ 一个 |
| 计算开销 | 较高 | 快约 10%-20%（少一次均值计算和一次广播减法） |

**去掉减均值为什么效果不降反升**：

1. **保留幅度信息**：减均值会把残差路径上的信号"重新居中"，破坏了向量长度（幅度）携带的信息；RMSNorm 只做尺度归一，幅度信息部分保留
2. **更少参数更不易过拟合**：去掉 $\beta$ 减少了可学习参数，实验上无性能损失
3. **计算更快**：大模型中每层都有 Norm，省下来的计算量相当可观

**主流大模型配置**：

| 模型 | Norm 类型 | Norm 位置 |
|------|-----------|-----------|
| 原始 Transformer / BERT | LayerNorm | Post-Norm |
| GPT-NeoX / Pythia | LayerNorm | Pre-Norm |
| LLaMA 1/2/3 | RMSNorm | Pre-Norm |
| Mistral / Mixtral | RMSNorm | Pre-Norm |
| Qwen 系列 | RMSNorm | Pre-Norm |

**PyTorch 实现**（PyTorch 2.4+ 提供内置 `nn.RMSNorm`，此前版本需手写）：

```python
import torch
import torch.nn as nn

class RMSNorm(nn.Module):
    """LLaMA 同款 RMSNorm，作用于最后一维 d"""
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d))  # (d,) 仅缩放参数，无 beta
        self.eps = eps

    def forward(self, x):
        rms = x.pow(2).mean(dim=-1, keepdim=True).sqrt() + self.eps  # (batch, seq_len, 1) 每 token 一个均方根
        return x / rms * self.gamma               # (batch, seq_len, d)

# 与 LayerNorm 对比：去均值化后均值不再为 0，但相对比例保留
h = torch.randn(2, 5, 768)      # (batch=2, seq_len=5, d=768)
ln = nn.LayerNorm(768)          # 严格零均值单位方差
rmsnorm = RMSNorm(d=768)        # 均值非零，仅整体幅度归一
out = rmsnorm(h)                # (2, 5, 768)
```

## 7. 横向对比

| 特性 | BN | LN | IN | GN | RMSNorm |
|------|----|----|----|----|---------|
| 统计量范围 | 跨 batch 同通道 | 单样本全特征 | 单样本单通道 | 单样本组内通道 | 单样本全特征 |
| 依赖 batch size | 强依赖 | 无关 | 无关 | 无关 | 无关 |
| 训练/推理不一致 | 有（滑动平均） | 无 | 无 | 无 | 无 |
| 可学习参数 | $\gamma,\beta$ | $\gamma,\beta$ | $\gamma,\beta$ | $\gamma,\beta$ | 仅 $\gamma$ |
| 减均值 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 典型场景 | CV 分类 | NLP / Transformer | 风格迁移 | 检测/分割（小 batch） | 大语言模型 |
| 代表模型 | ResNet | BERT / GPT | StyleGAN | Mask R-CNN | LLaMA / Qwen |

**选型建议**：

- CV 分类任务、batch size 充足 → **BN**
- NLP / Transformer → **LN 或 RMSNorm**（现代大模型选 RMSNorm）
- 目标检测/分割等小 batch 任务 → **GN**
- 风格迁移、图像生成 → **IN**

## 8. 具体例子

### 例子 1：BN 手算一个 mini-batch

**问题**：某通道的 batch 内 4 个样本取值为 $x = [-2, -1, 1, 2]$，$\gamma = 1$，$\beta = 0$，$\epsilon \approx 0$，计算 BN 输出。

**步骤**：

1. 计算均值：$\mu_B = \frac{-2-1+1+2}{4} = 0$
2. 计算方差：$\sigma_B^2 = \frac{4+1+1+4}{4} = 2.5$，标准差 $\sigma_B = \sqrt{2.5} \approx 1.581$
3. 逐元素归一化再缩放

**计算**：

$$\hat{x}_{-2} = \frac{-2-0}{1.581} \approx -1.265, \quad \hat{x}_{-1} \approx -0.632, \quad \hat{x}_{1} \approx 0.632, \quad \hat{x}_{2} \approx 1.265$$

**结果解读**：归一化后数据变为零均值、单位方差的 $[-1.265, -0.632, 0.632, 1.265]$。对 sigmoid 激活而言，$\hat{x} = 1.265$ 时的梯度约 $0.21$，远大于原始 $x = 2.5$（若分布漂移到此）时约 $0.07$ 的梯度——**BN 把激活值拉回非饱和区，梯度被放大了约 3 倍**。若 $\gamma = 2, \beta = 1$，输出变为 $\hat{x} \times 2 + 1$，网络可通过学习 $\gamma, \beta$ 恢复表达能力。

### 例子 2：LN 在 NLP 中如何处理"量纲统一"的词向量

**问题**：batch 内有两句话，每句用 4 维词向量表示（实际中是 768 维，这里简化）。句子 1 的 hidden state 为 $[1, 2, 3, 4]$，句子 2 为 $[2, 2, 2, 10]$。分别用 LN 和 BN 归一化，观察差异。

**步骤（LN，逐句子归一化）**：

句子 1：$\mu = 2.5$，$\sigma^2 = \frac{2.25+0.25+0.25+2.25}{4} = 1.25$，$\sigma \approx 1.118$

**计算**：

$$\text{LN}([1,2,3,4]) \approx [-1.342, -0.447, 0.447, 1.342]$$

句子 2：$\mu = 4$，$\sigma^2 = \frac{4+4+4+36}{4} = 12$，$\sigma \approx 3.464$

$$\text{LN}([2,2,2,10]) \approx [-0.577, -0.577, -0.577, 1.732]$$

**结果解读**：

- LN 下**每句话独立归一化**，无论句子内容多离谱（句子 2 有个异常大的第 4 维），都能被各自拉回稳定分布——且这个计算与其他句子无关，句子长度不同也完全不影响
- 若用 BN 对"第 1 维"跨两句话归一化：$\mu = 1.5$，$\sigma = 0.5$，得到 $[-1, 1]$——但这个统计量只基于 2 个样本，且"句子 A 的第 1 维和句子 B 的第 1 维"在不同语境下没有共同语义，统计量既不稳定也无意义。这正是 NLP 弃用 BN 的本质原因

### 例子 3：LayerNorm 与 RMSNorm 的数值对比

**问题**：对同一向量 $x = [1, 2, 3]$，分别计算 LayerNorm 和 RMSNorm 的输出（$\gamma = 1$，$\beta = 0$，$\epsilon \approx 0$）。

**步骤与计算**：

**LayerNorm**：$\mu = 2$，$\sigma^2 = \frac{1+0+1}{3} \approx 0.667$，$\sigma \approx 0.816$

$$\text{LayerNorm}([1,2,3]) = \left[\frac{-1}{0.816}, 0, \frac{1}{0.816}\right] \approx [-1.225, 0, 1.225]$$

**RMSNorm**：$\text{RMS}(x) = \sqrt{\frac{1+4+9}{3}} = \sqrt{4.667} \approx 2.160$

$$\text{RMSNorm}([1,2,3]) = \left[\frac{1}{2.160}, \frac{2}{2.160}, \frac{3}{2.160}\right] \approx [0.463, 0.926, 1.389]$$

**结果解读**：

- LayerNorm 输出严格零均值、单位方差，但向量 $[1,2,3]$ 本身"整体偏正、幅度递增"的信息被抹掉了
- RMSNorm 输出均值约 $0.926$（非零），**保留了"第 3 维 > 第 2 维 > 第 1 维"的相对比例与偏正特性**，只把整体幅度从 $\text{RMS} \approx 2.16$ 压到 1——这就是"保留幅度信息"的直观体现
- 计算上，RMSNorm 少了求均值和广播减法两步，在每层都含 Norm 的大模型中累积收益显著

## 9. 常见面试问题

### Q1：BN 的公式是什么？它为什么能加速训练？

**答**：

$$y = \gamma \cdot \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta$$

其中 $\mu_B, \sigma_B^2$ 是 mini-batch 内的均值和方差，$\gamma, \beta$ 是可学习参数。

加速训练的三个原因：

1. **缓解 ICS**：每层输入分布被稳定住，后层不用不停适应前层的分布漂移，层间解耦
2. **避免梯度饱和**：激活值被拉回非饱和区，sigmoid/tanh 的梯度不再趋近 0
3. **梯度更平滑**：损失面对权重的尺度不再敏感，可以用更大的学习率且不易发散

### Q2：BN 在训练和推理时有什么区别？为什么推理时不用 batch 统计量？

**答**：

- **训练**：用当前 mini-batch 的均值/方差，同时用滑动平均维护全局统计量
- **推理**：使用训练期间累积的**全局**均值/方差（固定常量）

推理时不用 batch 统计量的原因：推理可能只有单个样本（batch 统计量无意义甚至退化为零方差）；固定统计量保证输出**确定且可复现**；同时保证线上服务不同批次的请求结果一致。

**关键公式**：$\mu_{\text{global}} \leftarrow \lambda\mu_{\text{global}} + (1-\lambda)\mu_B$（动量滑动平均）。

### Q3：为什么 NLP/Transformer 用 LN 而不用 BN？

**答**：

1. **语义错位**：BN 对"batch 内不同样本的同一位置"归一化，但语言中任何词都可能出现在任何位置，同一位置的特征在不同样本间不同分布，统计量无意义
2. **变长序列**：batch 内句子长短不一，按位置对齐做统计需要 padding，引入噪声
3. **batch size 敏感**：NLP 任务（尤其大模型训练）有效 batch 内序列数往往不大，统计量噪声大
4. **一致性**：LN 训练推理行为完全一致，没有 BN 的两套统计量问题

LN 沿特征维度（词向量维度）归一化，该维度上各特征量纲一致（都是同一套 hidden state），统计量有意义。

### Q4：BN 和 LN 的核心区别是什么？

**答**：

一句话：**BN"竖着算"（跨样本、同特征），LN"横着算"（同样本、跨特征）**。

对形状 $[N, C, HW]$ 的输入：

- BN：$\mu, \sigma$ 在 $\{N, HW\}$ 维上算，每个通道一组统计量 → 统计量随 batch 变化
- LN：$\mu, \sigma$ 在 $\{C, HW\}$ 维上算，每个样本一组统计量 → 与 batch 完全无关

推论：BN 依赖 batch size 且训练/推理不一致；LN 两者皆无，但会"平均掉"通道间差异，在 CV 中会削弱各通道的判别性，所以 CV 更适合 BN。

### Q5：GN 是怎么提出的？它和 IN、LN 是什么关系？

**答**：

GN 的动机：检测/分割任务中受显存限制 batch 很小（1~4），BN 统计量噪声极大而失效。

GN 把每个样本的通道分成 $G$ 组，在**组内**算均值方差，完全不依赖 batch。三者关系（$C$ 个通道分 $G$ 组）：

- $G = 1$ → GN 退化为 **LN**
- $G = C$ → GN 退化为 **IN**
- 中间的 $G$（如 32）→ 兼顾统计稳定性（组内通道数够多）与通道间独立性

### Q6：BN 的正则化效果从哪里来？

**答**：

来自 **mini-batch 统计量的随机性**：每个 batch 只是从全体数据中抽样，其均值/方差与全局统计量有偏差，相当于给每层的输入注入了与 batch 组成相关的随机噪声。这种噪声：

1. 类似 Dropout 的"随机扰动"，防止神经元过度依赖特定共现模式
2. 使模型不能过度拟合训练集的精确统计特征

batch 越小、随机性越强、正则化越强——但太小统计量本身不可靠，需要在噪声有效性和统计可靠性之间权衡。这也是"用大 batch 训练时常配合额外的正则化手段（Dropout、随机深度）"的原因之一。

### Q7：Pre-Norm 和 Post-Norm 的区别？为什么大模型都用 Pre-Norm？

**答**：

- **Post-Norm**：$x = \text{Norm}(x + \text{Sublayer}(x))$，Norm 在残差之后，每层输出都被归一化。效果上限略高，但深层网络梯度路径被反复扰动，**训练不稳定、必须精细 warmup**
- **Pre-Norm**：$x = x + \text{Sublayer}(\text{Norm}(x))$，残差主干上没有 Norm，梯度可以沿主干**无阻碍直通**所有层。训练极稳定，对学习率和深度都鲁棒

大模型（LLaMA、GPT 系列、Qwen 等）层数深、训练成本极高，"训得稳"远比"上限高一点"重要，所以普遍选择 Pre-Norm。实验上 Post-Norm 与 Pre-Norm 的最终效果差距通常很小，而 Pre-Norm 几乎不需要调 warmup。

### Q8：RMSNorm 相比 LayerNorm 去掉了什么？为什么效果不降反升？

**答**：

RMSNorm 去掉了**减均值**（中心化）和参数 $\beta$：

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2}} \cdot \gamma$$

效果不降反升的原因：

1. **保留幅度信息**：减均值会破坏残差路径中信号向量的"整体幅度/偏置"信息，而幅度本身可能携带语义；RMSNorm 只做尺度归一
2. **参数更少**：去掉 $\beta$ 减少过拟合风险，且实验证明无性能损失
3. **计算更快**：少一次均值计算和一次广播减法，大模型每层都有 Norm，累计节省约 10%-20% 的 Norm 计算开销

### Q9：为什么 BN 在 batch size 很小时会失效？有什么缓解办法？

**答**：

BN 的统计量来自当前 batch。batch 小时：

1. **统计量噪声大**：用 2 个样本估计的均值/方差与全局分布偏差极大，归一化反而引入剧烈扰动
2. **训练/推理鸿沟扩大**：训练时 batch 统计量抖动剧烈，与固定的全局统计量差异更大

缓解办法：

1. **换 GN**：检测/分割任务的标准做法，不依赖 batch
2. **换 LN**：Transformer 类结构天然选择
3. **SyncBN（跨卡同步 BN）**：多 GPU 上汇总全局统计量，等效扩大 batch（常用于检测任务的骨干网络）
4. **Frozen BN**：用预训练模型的全局统计量并冻结（常见于把分类模型迁移到检测任务时）

### Q10：如果你从零训练一个 70B 的语言模型，Norm 相关的你会怎么设计？为什么？

**答**：

我会选择 **Pre-Norm + RMSNorm**（LLaMA 同款），理由：

1. **Pre-Norm 保证训练稳定性**：70B 模型层数极深，一次训练中断损失巨大，Pre-Norm 的稳定梯度通路把训崩风险降到最低，几乎不需要为 Norm 相关问题调 warmup
2. **RMSNorm 省计算**：去掉减均值和 $\beta$，Norm 计算快 10%-20%；Norm 位于每层残差路径上，调用次数 = 层数 × 2，累积节省可观
3. **保留幅度信息**：语言建模中 hidden state 的幅度（能量）携带信息，RMSNorm 只缩放不平移，对残差流更"温和"
4. **工程验证充分**：LLaMA/Mistral/Qwen 全系使用，生态与推理框架（vLLM、TensorRT-LLM）支持完善

唯一需要留意的是：Pre-Norm 下最终效果理论上限略低于精调的 Post-Norm，若追求极致效果且算力充裕，可考虑 Post-Norm + 周期性重缩放等折中方案（如 Sandwich-Norm），但工程风险更高。
