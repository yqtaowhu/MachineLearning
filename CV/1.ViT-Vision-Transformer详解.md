# ViT（Vision Transformer）详解

## 1. 概述

**一句话定义**：ViT（Vision Transformer）是把 NLP 中的 Transformer 架构直接搬到图像分类上的模型——它将图像切成固定大小的图像块（patch），每个 patch 线性映射为一个 token，然后像处理句子中的单词一样，用标准 Transformer Encoder 建模所有 patch 之间的全局依赖关系。

**为什么重要**：
- **范式转移**：证明了"只要数据和算力足够，纯 Transformer 不需要卷积先验也能在 CV 上做到 SOTA"，开启了 Vision Foundation Model（如 CLIP、SAM、DINOv2）的时代
- **统一架构**：视觉和语言可以用同一套 Transformer 骨干处理，为多模态（视觉-语言模型）铺平道路
- **可扩展性强**：遵循 Scaling Law，模型/数据规模增大时性能持续提升，且大模型在小数据上迁移效果优于 CNN
- **工业界标配**：当前主流视觉基座模型（ViT、Swin、DeiT、EVA、Qwen-VL 的视觉编码器）几乎全部基于 ViT 或其变体

> **直觉理解**：CNN 看图像像"拿着放大镜逐块扫描"——先看局部纹理，再逐层扩大感受野；ViT 看图像像"把照片剪成拼图碎片摊在桌上"——第一层就能同时比较任意两片碎片的关联，全局视野从一开始就存在。

**论文信息**：Dosovitskiy et al., *An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale*, ICLR 2021。

## 2. 核心原理

### 2.1 整体流程

ViT 的计算流程可以概括为五步：

```
输入图像 (H, W, 3)
    │ ① 切分：划成 N = (H/P)×(W/P) 个 patch，每个 patch 尺寸 P×P
    ▼
N 个扁平化 patch (N, P²·3)
    │ ② 线性投影：映射到 d 维 + 拼上 CLS token
    ▼
N+1 个 token (N+1, d)
    │ ③ 加上可学习的位置编码
    ▼
    │ ④ 堆叠 L 层 Transformer Encoder（MSA + MLP）
    ▼
CLS token 输出 (d,)
    │ ⑤ MLP Head 分类
    ▼
类别概率 (num_classes,)
```

关键设计：**除了 patch 切分和投影这一步，后面所有操作与 NLP 版 Transformer 完全一致**——这正是论文标题"An Image is Worth 16x16 Words"的含义。

### 2.2 Patch Embedding：把图像变成"单词"

把每张图像切成 $P \times P$ 大小的不重叠小块。对 224×224 的图像、 $P=16$ ：

$$N = \left(\frac{H}{P}\right) \times \left(\frac{W}{P}\right) = 14 \times 14 = 196 \text{ 个 patch}$$

每个 patch 原始维度为 $P^2 \cdot C = 16 \times 16 \times 3 = 768$ 维，用一个线性层投影到模型隐藏维度 $d$：

$$z_n = \mathrm{Flatten}(x_n) \mathbf{E} + \mathbf{e}^{0}_{pos}, \quad n = 1, \dots, N$$

符号说明：
- $x_n \in \mathbb{R}^{P \times P \times C}$：第 $n$ 个图像块
- $\mathbf{E} \in \mathbb{R}^{(P^2 C) \times d}$：可学习的投影矩阵（patch 尺寸远大于 1 时，它与"步长为 $P$、卷积核为 $P \times P$ 的卷积"完全等价）
- $\mathbf{e}^{0}_{pos} \in \mathbb{R}^{d}$：第 $n$ 个位置的位置编码（下一节详述）

> **实践提示**：官方实现就是用一层 `Conv2d(kernel_size=P, stride=P)` 完成"切块 + 展平 + 线性投影"三件事，效率远高于手工循环切块。

### 2.3 CLS Token 与位置编码

**CLS Token**：沿用 BERT 的做法，在序列头部拼接一个可学习向量 $\mathbf{z}^{(0)}_{cls} = [\text{CLS}] \in \mathbb{R}^{d}$。它不对应任何图像区域，作用是充当"信息汇聚点"——经过 L 层注意力后，全图信息被聚合到这一个向量上，最终只用它的输出接分类头。

**位置编码**：patch 被拉平成 1 维序列后，"第 3 行第 5 列"和"第 8 块"在序列里丢失了空间信息，注意力又是置换不变的（打乱 token 顺序结果不变），因此必须显式注入位置信息。ViT 采用**一维可学习绝对位置编码**：

$$\mathbf{z}^{(0)}_n = \mathbf{z}_n + \mathbf{e}_{pos}, \quad \mathbf{e}_{pos} \in \mathbb{R}^{(N+1) \times d}$$

- $\mathbf{e}_{pos}$ ： $(N+1) \times d$ 的可学习参数表（含 CLS 占位），随机初始化后随模型一起训练
- 对比：原始 Transformer 用固定的 sin/cos 函数；ViT 尝试过 2D 位置编码（分别编码行、列再相加），实验发现对分类任务帮助很小，最终采用最简单的一维版本

**为什么能行**？CNN 靠卷积核天然知道"空间邻近"，而 ViT 把空间结构交给数据去学——只要数据和算力够，模型能自己学到"哪些位置组合是有意义的"。

### 2.4 Transformer Encoder 块

每个 token $z_n$ 经过 $L$ 层相同结构的 Encoder，每层包含两个子层（ViT 原文采用 Post-LN 结构）：

$$\tilde{\mathbf{z}}_n = \mathrm{MSA}\left(\mathrm{LN}(\mathbf{z}^{l-1}_n)\right) + \mathbf{z}^{l-1}_n$$

$$\mathbf{z}^{l}_n = \mathrm{MLP}\left(\mathrm{LN}(\tilde{\mathbf{z}}_n)\right) + \tilde{\mathbf{z}}_n$$

符号说明：
- $\mathrm{LN}$：LayerNorm，对每个 token 的 $d$ 维特征独立归一化
- $\mathrm{MSA}$：多头自注意力（Multi-Head Self-Attention）
- $\mathrm{MLP}$：两层前馈网络，隐藏维度 $4d$，激活函数 GELU
- 残差连接保证梯度可以直通浅层

**缩放点积注意力**（单头）：

$$\mathrm{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \mathrm{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

- $\mathbf{Q} = \mathbf{X}\mathbf{W}^Q, \mathbf{K} = \mathbf{X}\mathbf{W}^K, \mathbf{V} = \mathbf{X}\mathbf{W}^V$，均由同一份输入 $\mathbf{X} \in \mathbb{R}^{(N+1) \times d}$ 线性映射而来（"自"注意力）
- $\sqrt{d_k}$：缩放因子，防止点积过大把 softmax 推入梯度饱和区
- 每个 patch 都可以直接"看到"其他所有 patch——**单层感受野即为全局**，这是与 CNN 最本质的区别

**多头机制**：把 $d$ 维拆成 $h$ 份（ViT-B: $d=768, h=12$，每头 $d_k = 64$ 维），各头在不同子空间学不同的关联模式（如颜色、纹理、形状关系），最后拼接再投影：

$$\mathrm{MSA}(\mathbf{X}) = \big[\mathrm{head}_1; \dots; \mathrm{head}_h\big]\mathbf{W}^{O}$$

### 2.5 分类头与损失函数

只取最后一层 CLS token 的输出 $\mathbf{z}^{L}_{cls}$，经过一个 MLP 头（Linear + tanh 近似 GELU + Linear）得到类别 logits $y \in \mathbb{R}^{K}$，训练目标为标准交叉熵：

$$\mathcal{L} = -\sum_{i=1}^{K} \hat{y}_i \log \frac{\exp(y_i)}{\sum_{j=1}^{K} \exp(y_j)}$$

- $\hat{y}_i$：真实标签的 one-hot 分布
- $K$：类别数（如 ImageNet 的 1000）

> **细节**：CLS token 经过 LN 后其范数会持续增长、数值过大导致训练后期不稳定（"CLS 坍缩"现象，见 Zhai et al., 2022），后续工作普遍改用 **average pooling**（对所有 patch token 输出取均值）或 **attention pooling** 作为图像级表征，效果更好。

## 3. 重要性质与设计分析

### 3.1 计算复杂度：Attention vs Convolution

对一个 $M \times M$ 、 $d$ 维的特征图（令序列长度 $N = M^2$）：

$$\text{FLOPs}_{conv} = 2M^2 \cdot d^2 \cdot k^2$$

$$\text{FLOPs}_{self-attn} = 2M^2 \cdot d^2 + 2M^4 \cdot d$$

- 第一项是线性投影，第二项是注意力图 $\mathbf{Q}\mathbf{K}^\top$ 的计算
- **临界点**：当 $k \gt M$（或 $d \gt M^2$，即特征图很小时）卷积更贵；当 $k \lt M$ 且 $d \lt M^2$（高分辨率、浅通道）时 attention 反而更省
- 直觉：卷积的成本随**核面积** $k^2$ 增长，attention 的成本随**序列长度平方** $M^4$ 增长；224×224 输入切成 196 个 token 后序列很短，二次方开销完全可接受
- **二次方复杂度是 ViT 用于检测/分割等高分辨率任务的主要瓶颈**，由此催生了 Swin 的窗口注意力、线性注意力等一系列工作

### 3.2 参数量计算

以 ViT-B/16（ $d=768, L=12, h=12$ ）为例，参数主要来自四块：

| 模块 | 公式 | ViT-B/16 参数量 |
| --- | --- | --- |
| Patch Embedding | $(P^2 C) \cdot d + d$ | $768 \times 768 \approx 0.59\text{M}$ |
| 位置编码 | $(N+1) \cdot d$ | $197 \times 768 \approx 0.15\text{M}$ |
| 每层 Encoder × L | $4d^2(\text{QKV+O}) + 8d^2(\text{MLP}) + \text{LN/偏置}$ | $12 \times 7.06\text{M} \approx 84.7\text{M}$ |
| 分类头 | $d \cdot K + K$ | $\approx 0.77\text{M}$ |

每层 Encoder 主导项： $\underbrace{4d^2}_{\text{注意力投影}} + \underbrace{8d^2}_{\text{MLP } (d \to 4d \to d)} = 12d^2 \approx 7.08\text{M}$。合计约 **86M**，与官方标称的 86.6M（含 BN/LN 参数）一致。

### 3.3 归纳偏置：CNN 的先验 vs Transformer 的灵活性

**归纳偏置**（inductive bias）= 模型结构自带的"世界应该长什么样"的假设：

| 归纳偏置 | CNN | ViT |
| --- | --- | --- |
| 局部性（邻近像素相关） | ✅ 卷积核硬编码 | ❌ 靠位置编码软学习 |
| 平移等变性 | ✅ 权值共享 | ❌ 需要数据自己学 |
| 组合层次性 | ✅ 逐层堆叠 | ❌ 层级扁平（靠深度） |
| 全局依赖建模 | ⚠️ 需堆很深才有大感受野 | ✅ 单层即全局 |

**核心结论**（论文实验）：归纳偏置是"数据不够时的拐杖"。在中小数据集（CIFAR-100、ImageNet-1k）上直接训练 ViT 打不过同规模 ResNet；但在 **ImageNet-21k（1400 万张）或 JFT-300M（3 亿张）** 上预训练后，ViT 反超 CNN，且规模越大优势越明显——**大数据可以让模型抛弃人工先验、自己学出先验**。

### 3.4 Patch 大小的选择

- patch 数 $N = (H/W)^2 / P^2$ 与 $P^2$ 成反比，序列越短 attention 计算越快（二次方关系），但**细粒度信息丢失越多**
- 常用配置：分类任务 $16 \times 16$（ImageNet）；高分辨率/检测用 $14 \times 14$ 或更小的 patch + 更大模型
- 论文观察：**大分辨率的收益大于小 patch**——同算力预算下，宁可"大 patch + 高分辨率输入"，如 ViT-H/14 @ 512×512 优于 ViT-H/8 @ 256×256

### 3.5 Pre-Norm vs Post-Norm

- ViT 原文用 **Post-LN**（残差分支外做 LN），沿用 BERT 惯例，在小规模上没问题
- 深层 ViT（ $L \ge 24$ ）中 Post-LN 容易梯度爆炸、对超参敏感；**Pre-LN**（LN 放到子层内部、残差主路上不做变换）训练显著更稳定，因此 DeiT、Swin 及几乎所有后续视觉 Transformer 都改用 Pre-LN
- 一句话：层数越深，Pre-Norm 越香

## 4. 与其他概念的关系

1. **与 NLP Transformer**：ViT = 原封不动的 BERT 编码器 + "图像分块 tokenize"前端。差别仅在输入表示（patch vs 词）与位置编码方式（可学习绝对位置 vs sin/cos）。
2. **与 CNN（ResNet）**：patch embedding 卷积（kernel=stride=P）相当于把 ResNet 的 stem 卷积核从 7×7/stride 2 换成 16×16/stride 16，即"更早、更猛地降采样"；此后的 attention 替换了卷积。Swin 则反向融合——保留卷积式的滑窗局部注意力，可视为"用窗口重新引入 CNN 局部性先验"。
3. **与混合架构（ConvNeXt、RegNet+attention）**：证明二者并非取代关系——ConvNeXt 给纯 CNN 补上 ViT 的训练配方（大 kernel、GELU、LayerNorm、更强增广）后仍能追平 ViT，说明**训练策略与数据规模的贡献可能大于架构本身**。
4. **与下游视觉任务**：ViT 输出的逐 patch token 序列天然携带空间信息（reshape 回 14×14 网格），可直接作为检测（DETR）、分割（SEEM/Segment Anything）的骨干特征，无需 FPN 式改造。
5. **与多模态（CLIP）**：ViT 把图像变成 token 序列后，图像和文本进入了同一表示空间，才使 CLIP 的对比学习图文对齐、以及 LLM 视觉编码器（如 Qwen-VL、LLaVA 中的 vision tower）成为可能。

## 5. 具体例子

### 例子 1：手算一个 4×4 图像的 Patch Embedding

**问题**：用最小的数字走一遍"图像 → token"流程，验证维度变化。

**步骤**：设输入为 4×4 单通道图像，patch 大小 $P=2$，目标维度 $d=2$。图像被切成 $N = (4/2)^2 = 4$ 个 patch，每个 patch 展平后是 $P^2 C = 4$ 维向量：

$$\text{patch}_1 = [1,\ 0,\ 2,\ 1]$$

为简化，取投影矩阵 $\mathbf{E}$ 为单位阵（前 2 维保留，实际为 $4 \times 2$ 矩阵），则：

**计算**：

$$\mathbf{z}_1 = [1, 0, 2, 1] \cdot \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \\ 0 & 0 \end{bmatrix} = [1, 0]$$

若位置编码 $\mathbf{e}_{pos,1} = [0.1,\ -0.1]$，则最终 token 为 $[1.1,\ -0.1]$。4 个 patch 得到 4 个 token，再拼上 CLS，序列长度为 $4+1=5$。

**结果解读**：每个 token 是"一个 2×2 图像块的 2 维压缩表示"；序列长度 = patch 数 + 1。真实模型只是把 $4 \to 768$ 、 $2 \to 768$ 放大，流程完全一致。

### 例子 2：ViT-B/16 参数量与算力核算

**问题**：面试常要求现场估算 ViT 的参数量。以 ViT-B/16 @ 224×224 为例。

**步骤与计算**：
1. patch 数： $(224/16)^2 = 196$ ；patch 原始维度： $16 \times 16 \times 3 = 768$
2. Patch Embedding： $768 \times 768 + 768 \approx 0.59\text{M}$
3. 位置编码： $197 \times 768 \approx 0.15\text{M}$
4. 每层 Encoder：注意力 $4d^2 \approx 2.36\text{M}$ + MLP $8d^2 \approx 4.72\text{M}$ ≈ $7.07\text{M}$，12 层共 $\approx 84.8\text{M}$
5. 分类头（1000 类）： $768 \times 1000 \approx 0.77\text{M}$

$$\text{总计} \approx 0.59 + 0.15 + 84.8 + 0.77 \approx 86.3\text{M}$$

**结果解读**：与官方 86.6M 吻合（差异来自 LN/偏置）。对比 ResNet-50：参数 25M、单图 FLOPs ≈ 4.1 GFLOPs；ViT-B/16 参数 86M、单图 FLOPs ≈ 17.6 GFLOPs——**ViT 的"注意力全局视野"是用更高的算力和更大的预训练数据换来的**。

### 例子 3：小数据集迁移——ViT 什么时候打不过 ResNet

**问题**：团队只有 5 万张医疗影像，直接训练 ViT-B/16 合适吗？

**步骤**：对照论文结论设计决策：
- 从零训练：ImageNet-1k 量级都嫌数据少，5 万张直接训 ViT 会严重过拟合（缺局部性先验），预计明显差于 ResNet
- 迁移学习：改用 **ImageNet-21k 预训练的 ViT + 微调**。论文数据：在 CIFAR-100（6 万张）上，预训练 ViT-L/16 达 95.41%，超过当时最强正则化 ResNet（95.18%）；数据集越小、预训练模型越大，相对收益越明显

**结果解读**：ViT 的归纳偏置弱 ⇒ 从小数据"自学结构"难，但预训练已经把先验"学好了"⇒ 小数据下游任务应使用**大预训练 ViT 微调**，而非小 ViT 从零训练。这正是"大模型是更好的老师"（模型越大、任务无关表征迁移越强）的体现。

## 6. PyTorch 极简实现

```python
import torch
import torch.nn as nn
import math

class PatchEmbed(nn.Module):
    """图像切块 + 线性投影, 用一步卷积实现"""
    def __init__(self, img_size=224, patch_size=16, in_chans=3, embed_dim=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2  # N=196
        # kernel=stride=patch_size: 每个 patch 独立投影, 互不重叠
        self.proj = nn.Conv2d(in_chans, embed_dim,          # (B,3,224,224) -> (B,768,14,14)
                              kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        x = self.proj(x)                 # (B, embed_dim, 14, 14)
        return x.flatten(2).transpose(1, 2)  # (B, N=196, embed_dim) 拉平成 token 序列

class Attention(nn.Module):
    def __init__(self, dim=768, num_heads=12):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = dim // num_heads   # d_k=64, 各头在 64 维子空间独立计算
        self.scale = self.head_dim ** -0.5 # 1/sqrt(d_k) 缩放因子
        self.qkv = nn.Linear(dim, dim * 3, bias=False)  # 一次算出 Q,K,V
        self.proj = nn.Linear(dim, dim)                 # 多头拼接后的输出投影

    def forward(self, x):
        B, N, C = x.shape                          # (B, N+1, 768), N+1 含 CLS
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, self.head_dim)
        q, k, v = qkv.permute(2, 0, 3, 1, 4)       # 各为 (B, 12头, N+1, 64)
        attn = (q @ k.transpose(-2, -1)) * self.scale      # (B, 12, N+1, N+1) 注意力图
        attn = attn.softmax(dim=-1)                        # 每行对"所有 token"归一化
        out = (attn @ v).transpose(1, 2).reshape(B, N, C)  # 拼回 (B, N+1, 768)
        return self.proj(out)

class TransformerLayer(nn.Module):
    """Pre-Norm 结构的单层 Encoder (工程上比原文 Post-Norm 更稳)"""
    def __init__(self, dim=768, num_heads=12, mlp_ratio=4):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn = Attention(dim, num_heads)
        self.norm2 = nn.LayerNorm(dim)
        hidden = int(dim * mlp_ratio)              # MLP 中间层 4d=3072
        self.mlp = nn.Sequential(
            nn.Linear(dim, hidden), nn.GELU(), nn.Linear(hidden, dim))

    def forward(self, x):
        x = x + self.attn(self.norm1(x))   # 残差1: 全局信息交流
        x = x + self.mlp(self.norm2(x))    # 残差2: 逐 token 非线性加工
        return x

class ViT(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_chans=3,
                 num_classes=1000, dim=768, depth=12, heads=12):
        super().__init__()
        self.patch_embed = PatchEmbed(img_size, patch_size, in_chans, dim)
        # CLS token + 可学习一维绝对位置编码 (N+1 个位置)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.patch_embed.num_patches + 1, dim))
        self.layers = nn.ModuleList([TransformerLayer(dim, heads) for _ in range(depth)])
        self.norm = nn.LayerNorm(dim)
        self.head = nn.Linear(dim, num_classes)    # 只用 CLS 输出做分类

    def forward(self, x):
        B = x.shape[0]
        x = self.patch_embed(x)                          # (B, 196, 768)
        cls = self.cls_token.expand(B, -1, -1)           # (B, 1, 768)
        x = torch.cat([cls, x], dim=1) + self.pos_embed  # (B, 197, 768)
        for layer in self.layers:
            x = layer(x)                                 # 维度不变, 表示不断精炼
        return self.head(self.norm(x[:, 0]))             # 取 CLS (B, 768) -> (B, 1000)

# 形状自检: 实测输出 (2, 1000)、参数量 86.5M, 与官方 ViT-B/16 (86.6M) 一致
model = ViT()
x = torch.randn(2, 3, 224, 224)      # (B, C, H, W)
print(model(x).shape)                # torch.Size([2, 1000])
print(sum(p.numel() for p in model.parameters()) / 1e6, "M")
```

## 7. 常见面试问题

**Q1：用一句话解释 ViT 是怎么"看"图像的？**

把图像切成 16×16（或类似大小）的不重叠 patch，每个 patch 展平后线性投影成一个 token，加上位置编码后送入标准 Transformer Encoder 编码，最后取 CLS token 的输出做分类。图像块之于 ViT，正如词之于 BERT。

**Q2：patch embedding 和卷积是什么关系？**

当 patch 之间不重叠时，"切块 + 展平 + 线性投影"与一层 `Conv2d(kernel_size=P, stride=P)` 完全等价——卷积核覆盖的区域恰好是一个 patch。只有当 patch 有重叠（stride 小于 kernel）时，才存在二者不等价的更一般形式。

**Q3：为什么 ViT 需要位置编码？不加会怎样？**

自注意力计算 $\mathrm{softmax}(\mathbf{Q}\mathbf{K}^\top/\sqrt{d_k})\mathbf{V}$ 对 token 顺序是**置换不变**的：把 196 个 patch 打乱，CLS 输出完全相同——猫和背景的位置互换模型无法区分。位置编码（ViT 用可学习一维绝对位置编码）把空间信息重新注入序列，缺失它 ViT 退化为"对 patch 集合做无序集合编码"，分类精度大幅下降。

**Q4：ViT 单层就能建模全局依赖，为什么说这是双刃剑？**

好处：不必像 CNN 那样堆几十层扩大感受野，长距离关系（图像两端物体的关联）一层即可交互。坏处：(1) attention 对序列长度是 $O(N^2)$ 复杂度，高分辨率图像（patch 数多）显存和算力爆炸；(2) 全局注意力缺乏局部性先验，中小数据上容易学到"无意义的远距离关联"而过拟合。Swin 的窗口注意力、各种线性注意力都是针对第一点的修补。

**Q5：为什么从零训练 ViT 在小数据集上表现差，而预训练后迁移却很强？**

CNN 的局部性、平移等变性是人工注入的强归纳偏置，小数据下"少走弯路"；ViT 偏置几乎为零，需要海量数据自己统计出视觉规律，ImageNet-1k 量级不够，需 100M+ 级数据（JFT）。但预训练一旦完成，ViT 从大数据中"学出的先验"比人工设计的更贴合真实世界，因此微调到大/小下游任务上都强于 CNN（论文：模型越大迁移收益越大）。

**Q6：现场估算：224×224 输入、patch=14、 $d=1024$ 、 $L=24$ 的 ViT-L/14 大致多少参数？**

patch 数 $N=(224/14)^2=256$；patch embedding: $14^2 \times 3 \times 1024 \approx 0.6\text{M}$；每层 $\approx 12d^2 = 12.6\text{M}$（QKV+O 共 $4d^2$，MLP 共 $8d^2$），24 层 $\approx 302\text{M}$；位置编码 + 分类头 < 3M。总计 $\approx 300\text{M}$，与官方 ViT-L/14 的 304M 一致。记住主干近似公式 $\approx 12 L d^2$。

**Q7：CLS token 一定可靠吗？有哪些替代方案？**

不一定。CLS 本质是"免费的注意力黑洞"，训练中可能吸收过大范数导致后期不稳定（CLS 坍缩），且最后层大量 patch token 的聚合信息没有直接被监督利用。替代方案：(1) 全部 patch token 输出取 average pooling（论文附录验证对超参更鲁棒）；(2) attention pooling / perceiver resampler（BLIP-2、Qwen-VL 用后者做 token 压缩）；(3) 多 token 输出接多个头。

**Q8：ViT 中的 LayerNorm 起什么作用？为什么用 LN 不用 BN？**

LN 对每个 token 的 $d$ 维特征独立归一化，同时 MLP 的残差结构依赖稳定缩放。不用 BN 的原因：BN 沿 batch 维统计，序列/样本表示长度可变（检测、分割、多模态场景）时统计量定义不稳；BN 还依赖大 batch、训练推理行为不一致。LN 逐 token 归一化，与 batch 和序列长度均无关，天然适合变长 token 序列。

**Q9：Swin Transformer 针对 ViT 做了哪些改造？为什么检测/分割偏爱 Swin？**

三个改造：(1) **移位窗口注意力**——只在 $7 \times 7$ 窗口内做 attention（复杂度从全局 $N^2$ 降为窗口内线性），相邻层窗口错位实现跨窗交互；(2) **层次化结构 + 下采样**——输出多尺度特征图（类似 CNN 的 C2~C5），可直接对接 FPN/检测头；(3) **相对位置偏置**替代绝对位置编码，更好泛化到不同分辨率。ViT 输出是单尺度定长序列，用于稠密预测需要额外设计，而 Swin 保留了 CNN 的多尺度先验，因此更适合作为检测/分割 backbone。

**Q10：既然 ViT 依赖大数据，工程师在没有亿级数据时如何用好它？**

三条路：(1) **迁移学习**——直接用公开预训练 ViT（ImageNet-21k、DINOv2、CLIP vision encoder）微调，冻结浅层只调深层可进一步防过拟合；(2) **强数据增广**——DeiT 证明用 RandAugment、Mixup、CutMix、RandErasing + 蒸馏的正则化配方，ViT-B/16 在 ImageNet-1k 从零也能到 81.8%，说明"训练技巧"可部分弥补数据缺口；(3) **选择合适规模**——数据小时用 DeiT-Small/Tiny 或 CNN 混合架构，避免大模型在小数据上高方差。
